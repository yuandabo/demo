适配移动场景的教程浏览，扫码直达，消息联动

1

前台（PC 端用户侧）

面向所有 ERP 用户
入口与首页
✓
导航入口
顶部导航栏或侧边栏增加"教程中心"入口，全局可达
✓
教程首页
展示推荐教程、最近更新、热门教程等内容区块
✓
分类浏览
按系统 8 大模块分类（销售、项目、生产、采购、库存、人事财务、系统设置等）
浏览与检索
✓
教程列表页
支持分类筛选、关键词搜索、标签筛选
✓
教程详情页
图文/视频内容展示，步骤式操作引导
✓
目录侧边导航
同一分类下的上下篇教程快速跳转
用户互动
✓
收藏与历史
教程收藏、浏览历史记录
✓
评价与反馈
教程是否有帮助、留言补充说明
✓
分享
生成教程链接，分享给同企业同事
场景联动（扩展方向） 实习生自由发挥
✓
系统内嵌引导
在具体功能页面展示关联教程入口，如 BOM 管理页面右下角"查看教程"可发挥
✓
新手引导
首次使用某模块时弹出推荐教程，帮助用户快速上手可发挥
✓
按角色推荐
采购角色优先展示采购/库存教程，管理层优先展示审批/报表教程可发挥
2

后台（管理端）

面向运营/管理员
内容管理
✓
教程 CRUD
教程的新建、编辑、删除、复制
✓
富文本编辑
图文混排编辑器，支持视频上传/嵌入
✓
状态管理
草稿、待审核、已发布、已下架四种状态流转
目录管理
✓
分类树管理
支持多级分类的新增、编辑、拖拽排序、启停用
✓
教程排序
教程与分类的关联、排序调整、置顶设置
✓
模块映射
分类与 ERP 系统模块的映射关系维护，用于场景联动推荐
审核流程
✓
审核队列
教程提交审核，支持审核通过/驳回，驳回需填写原因
✓
AI 生成审核
预留 AI 自动生成教程的审核队列（对接后续 AI 自动生成需求）
数据统计 实习生自由发挥
✓
浏览与互动统计
教程浏览量、收藏量、完成率等核心指标可发挥
✓
反馈分析
用户反馈汇总，标记"没帮助"的教程优先优化可发挥
✓
覆盖度统计
按模块/分类统计教程内容覆盖情况，发现空白区可发挥
3

移动端（小程序）

面向移动办公用户
浏览与学习
✓
教程列表与搜索
分类浏览、关键词搜索，适配移动端列表交互
✓
教程详情页
移动端适配的图文/视频展示，字号可调
✓
收藏与历史
收藏教程、浏览历史同步（与 PC 端数据打通）
场景联动（扩展方向） 实习生自由发挥
✓
首页/工作台推荐
在小程序首页或工作台推荐与当前角色相关的教程可发挥
✓
消息推送关联
收到审批待办时推送审批操作教程等联动场景可发挥
✓
扫码直达
PC 端页面展示二维码，扫码在小程序打开对应教程可发挥

教程分类 ↔ ERP 系统模块映射

销售管理 项目管理 文件管理 生产制造 采购管理 库存管理 人事财务 系统设置 开放平台 新手入门 最佳实践 常见问题

🎯 实习生自由发挥空间

交互与体验设计

教程详情页的阅读体验由实习生自主设计：步骤进度条、目录锚点、字号调节、阅读进度保存等交互细节。

数据统计看板

后台统计页面的指标选取和可视化形式开放定义，可自由选择图表类型、维度组合和展示风格。

场景联动方案

系统内嵌引导、角色推荐、消息联动等扩展功能，可自主规划优先级和实现方案。

移动端差异化

小程序端是否有独立于 PC 端的特色功能（如学习打卡、积分激励、进度徽章等），可自由探索。
