## 2. 验收标准（AC）

### 2.1 全局业务规则（AC-RULE）

#### 状态枚举定义（教程 / 分类）

| 编号 | 状态类型 | 状态值 | 语义说明 | 来源 |
|---|---|---|---|---|
| AC-RULE-01 | 教程状态 | 草稿 | 创作中，仅作者后台可见；入口：新建 / 复制 / 被驳回（含回审版被驳回）/ 待审核撤回 | §3.5 / §6 |
| AC-RULE-02 | 教程状态 | 待审核 | 等待管理员处理；无线上过审版本的待审核教程（新建 / 复制后提审）在前台 / 搜索 / 推荐 / 小程序均不可见，直达 URL 访问显示"该教程不存在或暂不可见"提示页（PRD 未明示直达表现，本条为验收兜底定义）；存在线上过审版本且**回审来源为已发布态**的回审教程在待审核期间继续展示该版本（见 AC-FN-10 / AC-FN-19，PRD §6 前台可见性规则②）；**回审来源为已下架态**的回审教程维持不可见（PRD §6 规则④，断言见 AC-EG-18） | §3.5 / §6 |
| AC-RULE-03 | 教程状态 | 已发布 | 三端可见（前台列表 / 搜索 / 推荐 / 小程序） | §3.5 / §6 |
| AC-RULE-04 | 教程状态 | 已下架 | 前台不可见；收藏夹与浏览历史标注"已下架" | §3.5 / §6 |
| AC-RULE-05 | 教程状态机 | 合法迁移集 | 草稿→待审核（提审）；待审核→已发布（通过）；待审核→草稿（驳回或撤回）；已发布→待审核（编辑保存回审）；已发布→已下架（下架）；已下架→已发布（重新发布，内容未变不重审）；已下架→待审核（编辑保存回审，内容已变需重审）；草稿→删除（仅纯草稿：从未通过审核、无线上过审版本）。集合之外的迁移（示例：草稿态直接调用发布接口、已下架态未编辑直接调用提审接口）后端一律拒绝 | §3.5 / §9 |
| AC-RULE-06 | 分类状态 | 启用 | 前台宫格与筛选树可见，参与角色推荐与内嵌入口命中集 | §7.8 |
| AC-RULE-07 | 分类状态 | 停用 | 前台宫格与筛选树隐藏，推荐与内嵌入口命中集排除该分类，关键词搜索不返回该分类下教程（检索范围排除停用分类内容，PRD §7.2）；其下已发布教程仍可经收藏 / 历史 / 直达链接访问 | §7.2 / §7.8 / §13 |

#### 计算规则

| 编号 | 规则名称 | 公式 | 精度 / 格式 | 来源 |
|---|---|---|---|---|
| AC-RULE-08 | 浏览量 | 打开详情页次数（不去重，口径在看板明示）；看板总览指标仅统计当前前台可见口径的教程（已下架教程历史计数不计入，与列表可对账）；覆盖度"已发布教程数"按前台可见口径统计（回审期间旧版在线计入） | 整数，默认 0 | §7.9 / §13 |
| AC-RULE-09 | 收藏量 | 当前有效收藏数（取消收藏即减 1） | 整数 | §7.9 |
| AC-RULE-10 | 有帮助率 / 没帮助占比 | 有帮助率 = 有帮助数 ÷（有帮助数 + 没帮助数）；没帮助占比 = 没帮助数 ÷（有帮助数 + 没帮助数），两者互补（和为 100%） | 百分比；零反馈（分母为 0）教程两项均显示"—"，不参与 >50% 标红判定，且不计入平均有帮助率计算 | §7.9 |
| AC-RULE-11 | 阅读进度 | 按滚动位置计算的百分比；同一用户同一教程仅一条记录，覆盖更新；跨端取最新值 | 0~100% 整数 | §6 / §7.3 |
| AC-RULE-12 | 打卡积分与徽章 | 每日打卡 1 次 +10 积分；坚持者徽章 = 连续 7 天打卡；百科达人徽章 = 累计完成 20 篇教程（完成 = 该用户对该教程阅读进度达 100%，口径同 AC-RULE-13 分子）；中断仅清连续天数，不清积分 | 整数 | §7.10 / §6 |
| AC-RULE-13 | 完成率 | 进度 100% 的历史条数 ÷ 历史总条数 | 百分比；本期仅口径定义与数据留存，v1.1 上看板（PRD §13 开放问题 4），本期无看板消费条目属预期 | §7.9 / §13 |
| AC-RULE-14 | 复制教程 | 新草稿标题 = 源标题 + "（副本）"（分享数一并清零）；源标题 + 4 字后缀 ≤100 字时不截断，超过 100 字时截断源标题至 96 字再拼接后缀（96+4=100，不超 AC-RULE-18 上限，兜底定义）；浏览量 / 收藏量 / 有帮助数 / 没帮助数清零；新教程状态 = 草稿 | — | §7.6 |
| AC-RULE-15 | 评价唯一性 | 每篇教程每人仅一条反馈记录，可在有帮助 / 没帮助之间修改切换 | — | §6 / §7.3 |
| AC-RULE-16 | 推荐位规则 | 取数口径 = PRD §6 前台可见性规则（启用分类 + 存在线上过审版本 + 未下架，回审期间按旧版数据参与排序）。已登录：按用户 ERP 角色匹配分类模块映射，取命中集内已发布教程浏览量 Top6；未登录：全站已发布教程浏览量 Top6；命中集不足 6 条时展示实际数量 | Top6（不足时为实际数量） | §6 / §7.1 |
| AC-RULE-17 | 首页区块规则 | 取数池 = 前台可见教程（PRD §6 口径，回审期间旧版在线计入，与推荐位同口径）。最近更新 = 按更新时间倒序 Top6；热门教程 = 按浏览量倒序 Top6；分类宫格 = 12 个启用一级分类（8 大模块 + 新手入门 / 最佳实践 / 常见问题 / 开放平台），角标 = 该分类前台可见教程数，0 篇显示"待补充" | Top6 | §6 / §7.1 | §7.1 |

#### 字段格式规范

| 编号 | 字段 | 格式 | 来源 |
|---|---|---|---|
| AC-RULE-18 | 教程必填与长度 | 标题必填 ≤100 字；所属分类必填（仅启用节点，唯一归属）；摘要必填 ≤200 字；图文正文必填（富文本）；标签可选 ≤5 个；视频外链可选（mp4 直链）；长度越界（标题 >100 字、摘要 >200 字、标签 >5 个）时保存草稿与提审均阻断并高亮对应字段（校验机制同 AC-EG-01，兜底定义） | §6 |
| AC-RULE-19 | 驳回原因 | 必填 ≥5 字，前端阻断 + 后端校验双重校验；作者在编辑页顶部可见 | §6 / §7.7 |
| AC-RULE-20 | 留言 | 选填 ≤200 字；仅后台反馈分析可见，前台不展示 | §6 / §7.3 |
| AC-RULE-21 | 正文字号 | 三档：标准 / 大 / 特大；仅影响正文区域；档位本地记忆 | §7.3 |
