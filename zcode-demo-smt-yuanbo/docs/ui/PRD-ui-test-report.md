## 通过判定

- 判定标准：综合评分 ≥54/60（90%）且无单项 ≤4 → 通过
- 实际：**47/60（78.3%）**，无单项 ≤4，但总分未达线，且存在 1 个 P0（选角色登录缺失）+ 4 个 P1
- 结论：**❌ 不通过，需修复**。建议优先级：先修 P0-1 与 P1-3/P1-4（登录引导 + 后台主链路按钮），再统一 P1-2 数据口径，P1-5 与 P2 项随后批量处理；修复后按同口径复验

1. ui_admin_login.html 或新页面出现 6 角色卡，portal `.who` / m `role-pill` 可点击且能演示"未登录互动→登录→回原位"
2. 三端分类计数、MRP 教程计数一套数据；portal_list 页内三处数字一致
3. 新建按钮可进编辑器；下架有确认弹窗；行内操作有反馈

5. admin 背景统一 #f8fafc；m 字号三档命名与 PC 一致
