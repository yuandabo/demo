MRP 自动算料：从 BOM 到采购建议

MRP（Material Requirements Planning，物料需求计划）是云ERP生产采购链路的核心能力。本教程以「智能温控器 V2.3 收到 500 台销售订单」为例，演示从 BOM 检查 → 设置算料参数 → 执行运算 → 生成采购建议 的完整链路。学习完你将能够独立完成一次标准算料，预计耗时 8 分钟。点击步骤前的圆点可勾选完成，进度自动保存并同步到小程序端。

第 1 步 · 检查 BOM 完整性

进入生产 → BOM 管理，打开目标产品的 BOM 清单，确认参与运算的每一行子件信息准确无误：

  • 用量与单位：核对每个子件的单位用量（如 0603 电容 100nF 每台 24 颗），用量错误会被订单量放大成整批错料；
  • 损耗率：SMT 贴片类物料建议维护 1%~3% 损耗率，接插件可设 0；
  • 替代料关系：仅在 BOM 行中维护过替代关系的物料才会参与替代运算；
  • 多级 BOM：逐层展开确认子件齐全，「智能温控器 V2.3」为 4 级结构共 86 行。
✓

第 2 步 · 设置算料参数

打开生产 → MRP 算料 → 新建运算，按本次备料计划填写参数：

  • 需求来源：选择销售订单 SO-20260812-007（智能温控器 500 台）；
  • 需求日期：2026-08-30（客户约定交期，系统按采购提前期倒推下单截止日）；
  • 勾选「含在途采购」：已下采购单未到货的数量计入可用；
  • 勾选「扣减现有库存」：现有良品库存优先抵扣，避免重复采购；
  • 损耗率默认取 BOM 行设置，本次运算可临时覆盖。
✓

第 3 步 · 执行运算并解读缺料结果

点击开始运算，10 秒内输出结果清单。系统按「毛需求 − 现有库存 − 在途 = 净缺料」逐行计算，并按缺料量倒序排列，红色行为紧急缺料（不满足最晚下单日）：

🖼 截图占位MRP 算料结果页：缺料 3 项标红，顶部汇总「本次运算 86 项，缺料 3 项」
  • 0603 电容 100nF：需求 12,000，可用 8,400，缺料 3,600（紧急）；
  • STM32F103C8T6：需求 620，可用 180，缺料 440（紧急，建议按 450 采购覆盖损耗）；
  • 温控器主板 PCB：需求 500，可用 500，无需采购。
4

第 4 步 · 生成采购建议并转采购申请

确认缺料清单后进入收尾动作：

  • 勾选缺料行 → 点击生成采购建议，系统自动带出物料编码、建议采购量与建议交期；
  • 一键转采购申请，按物料默认供应商自动拆分为多张申请单；
  • 提交多级审批流（组长 → 采购经理），审批通过后可同步立创商城一键下单；
  • 下单后回到 MRP 结果页，对应行状态自动变为「在途」，下次运算自动抵扣。
⚠️ 注意事项 MRP 不会自动扣减「已分配给其它订单」的库存，请在参数中开启占用检查；替代料仅在 BOM 维护过替代关系才参与运算；建议每周一上午全量重算一次，避免在途数据过期导致重复采购。
