1第1步 · 进入安全库存设置

登录云ERP，依次打开 库存管理 → 安全库存设置，确认当前账套与仓库权限已开通。

  • 路径：库存管理 → 安全库存设置
  • 权限：仓库主管及以上角色可见

2第2步 · 选择仓库与物料范围

按仓库逐个配置，或按物料分类批量圈定需要设置安全库存的物料范围，建议先对 A 类物料启用。

🖼 截图占位：仓库与物料范围选择界面

3第3步 · 设置安全库存阈值与补货预警

填写最低库存、补货点与最大库存，勾选"低于补货点自动生成补货预警"。

🖼 截图占位（旧版界面 · 待替换）⚠ 驳回项：此截图含未发布界面，请替换为新版截图

4第4步 · 启用预警并配置消息通知

保存后启用预警规则，配置站内 + 小程序消息通知，低于补货点时采购与仓库角色同步收到提醒。

  1. 保存阈值规则并启用
  2. 在消息设置中勾选"补货预警"渠道
  3. 用测试物料验证预警触发链路
