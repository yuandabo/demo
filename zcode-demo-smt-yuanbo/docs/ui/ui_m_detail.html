MRP 自动算料：从 BOM 到采购建议

👁 浏览 2,341⭐ 收藏 187✍ 运营 · 李静更新于 08-15

MRP 自动算料把销售订单按 BOM 展开成物料需求，自动扣除现有库存与在途预计入库，算出净需求并生成建议采购量 / 建议生产量。本教程 4 步跑通全流程。

1
进入 MRP 运算并选择方案
  • 登录云ERP，进入 「生产制造 › MRP 运算」
  • 运算方案选「按销售订单」，也支持「预测 + 订单」混合
  • 圈定参与运算的订单：按客户、交期区间筛选
2
设置算料参数
  • BOM 版本：默认取最新生效版本，可手工锁定
  • 可用量 = 现有库存 + 预计入库 − 已分配
  • 安全库存天数、损耗率按物料档案带出，可单行覆盖

4
一键下达与跟踪
  • 建议采购量一键生成采购申请，进入审批流
  • 建议生产量转入生产工单，自动带出工艺路线
