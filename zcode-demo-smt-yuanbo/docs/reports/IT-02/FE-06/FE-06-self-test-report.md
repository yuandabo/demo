## 实测修复（本次会话补完，均可溯源）

1. **拖拽排序相邻移动静默失效**：变更过滤原按"位置 i 新 sort vs 位置 i 旧 sort"比较，相邻移动时两分类新 sort 恰等于对方旧 sort 而双双漏提交（仅尾部 gap 补位被提交，toast 误报成功）。改为按"分类自身新旧 sort"比较（Map id→旧 sort）。修复后实测 销售↔项目 互换提交 PUT×2、顺序即时更新。
2. **子分类 409 建议文案被覆盖**：教程类 409 弹窗会异步取教程清单作迁移建议，但子分类类 409 的空清单兜底文案（"请将该分类下的教程迁移…"）会覆盖正确的"请先删除或迁移其下子分类"建议。修复为仅教程类 409 才发起清单加载。
3. **折叠箭头未阻止冒泡**：点 ▶ 会同时触发行选中（原型 toggleKids 有 stopPropagation）。已补 stopPropagation 并实测表单目标不随折叠变化。

## 说明与偏差（均可溯源）

1. 树行删除按钮统一所有行提供（原型部分行无删除入口）——按任务页面元素表"树行=…+删除"。
2. 名称上限 50 字（原型 maxlength=20 为演示值）且不设 maxLength——保留超长输入以实测 ≤50 校验提示，任务校验表为口径。
3. 新增态排序默认值 = 当前一级最大 sort+1（原型 12 个一级时预填 13 同口径）；切换父分类后不重算（原型同行为，排序值可编辑）。
4. 阻断弹窗建议列前 3 篇教程名 + 总数（原型口径"等 3 篇"），取数走 GET /api/tutorials?all=1&categoryId（后端按子树收敛，含子分类教程）。
5. 弹窗阻断主文案直接采用后端 409 message（契约字面"该分类下还有 N 篇教程，请先移走"），前端仅补"无法删除："前缀与保护说明行。
