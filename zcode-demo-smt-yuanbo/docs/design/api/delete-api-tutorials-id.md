# DELETE /api/tutorials/:id

> 此文档为前后端共享的接口契约，任何变更需同步通知前后端开发者。

## 基本信息

| 字段 | 内容 |
|------|------|
| **接口路径** | DELETE /api/tutorials/:id |
| **所属模块** | 教程（后台·教程管理·删除） |
| **版本** | v1 |

## 请求

### Headers

| Header | 值 | 必填 | 说明 |
|--------|----|------|------|
| Content-Type | application/json | 否 | |
| Authorization | Bearer {token} | 是 | 需 admin / operator 登录 |

### 路径参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Integer | 是 | 教程 ID |

### 查询参数

无

### 请求体

无

## 响应

### 成功响应

```json
{
  "code": 0,
  "message": "已删除",
  "data": null
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| data | null | 物理删除纯草稿；后台列表移除，前台无影响（纯草稿本就不可见） |

### 失败场景

| HTTP 状态码 | code | 触发条件 | message 示例 |
|-------------|------|----------|--------------|
| 401 | 401 | 未登录 | "未登录或登录已失效" |
| 403 | 403 | 登录角色为 user | "无权限执行该操作" |
| 403 | 403 | 教程存在线上过审版本（published_content 非空：已发布 / 已下架 / 回审驳回或撤回落草稿但旧版仍在线）——删除保护 | "存在线上过审版本的教程不可删除，请以下架归档代替" |
| 403 | 403 | operator 删除非本人名下的纯草稿 | "无权限执行该操作" |
| 404 | 404 | 教程 id 不存在 | "教程不存在" |

## 业务规则

- 删除仅限"从未通过审核的纯草稿"（published_content IS NULL），二次确认由前端承载；存在线上过审版本的教程一律不提供删除，以下架归档代替，防误删线上内容（来源：PRD §7.6 删除保护、AC-OP-06、AC-RULE-05）
- 删除保护判定以"是否存在线上过审版本"为准，含已发布、已下架、以及因回审驳回/撤回落草稿但旧版仍在线的情况（来源：PRD §7.6）
- 权限：operator 仅可删除本人名下纯草稿（author_id=当前用户）；admin 可删除任意纯草稿（来源：AC-RULE-22/23、AC-EG-08、§10 权限矩阵）
- 纯草稿删除对前台无影响（纯草稿本就不可见，来源：AC-OP-06）

## 调用示例

### 正常请求

```bash
curl -X DELETE 'http://localhost:3000/api/tutorials/25' \
  -H 'Authorization: Bearer b7e2d9f4a1c80356'
```

### 预期响应

```json
{"code":0,"message":"已删除","data":null}
```
