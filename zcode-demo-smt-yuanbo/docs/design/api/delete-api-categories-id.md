# DELETE /api/categories/:id

> 此文档为前后端共享的接口契约，任何变更需同步通知前后端开发者。

## 基本信息

| 字段 | 内容 |
|------|------|
| **接口路径** | DELETE /api/categories/:id |
| **所属模块** | 分类（后台·目录管理） |
| **版本** | v1 |

## 请求

### Headers

| Header | 值 | 必填 | 说明 |
|--------|----|------|------|
| Content-Type | application/json | 否 | |
| Authorization | Bearer {token} | 是 | 需 admin 登录 |

### 路径参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Integer | 是 | 分类 ID |

### 查询参数

无

### 请求体

无

## 响应

### 成功响应

```json
{
  "code": 0,
  "message": "已删除",
  "data": null
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| data | null | 删除成功无业务数据返回；分类从后台分类树移除 |

### 失败场景

| HTTP 状态码 | code | 触发条件 | message 示例 |
|-------------|------|----------|--------------|
| 401 | 401 | 未登录 | "未登录或登录已失效" |
| 403 | 403 | 登录角色非 admin | "无权限执行该操作" |
| 404 | 404 | 分类 id 不存在 | "分类不存在" |
| 409 | 409 | 该分类（含其子分类）下存在任意状态教程，N 为教程总数 | "该分类下还有 3 篇教程，请先移走" |
| 409 | 409 | 该分类下存在子分类（需先处理子分类；工程兜底定义） | "该分类下存在子分类，请先处理" |

## 业务规则

- 删除保护：分类下存在任意状态（草稿/待审核/已发布/已下架）教程时阻断删除，提示"该分类下还有 N 篇教程，请先移走"，分类树中该分类仍存在；恢复方式=移动教程后重试（来源：PRD §7.8 / §9、AC-FN-13）
- 分类删除为管理员专属操作；删除需二次确认（前端交互）（来源：AC-RULE-22、§10 权限矩阵）
- 删除仅对"分类下无教程"的空分类放行（来源：PRD §3.5 分类状态机：启用→删除 需分类下无教程）
- 子分类存在时阻断为工程兜底定义（PRD 未明示，防止两级树悬挂孤儿节点）

## 调用示例

### 正常请求

```bash
curl -X DELETE 'http://localhost:3000/api/categories/15' \
  -H 'Authorization: Bearer f3a9c2e81b7d4f6a'
```

### 预期响应

```json
{"code":0,"message":"已删除","data":null}
```
