# POST /api/tutorials/:id/submit

> 此文档为前后端共享的接口契约，任何变更需同步通知前后端开发者。

## 基本信息

| 字段 | 内容 |
|------|------|
| **接口路径** | POST /api/tutorials/:id/submit |
| **所属模块** | 教程（后台·教程管理·提交审核） |
| **版本** | v1 |

## 请求

### Headers

| Header | 值 | 必填 | 说明 |
|--------|----|------|------|
| Content-Type | application/json | 是 | |
| Authorization | Bearer {token} | 是 | 需 admin / operator 登录 |

### 路径参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Integer | 是 | 教程 ID |

### 查询参数

无

### 请求体

无（空对象 `{}` 或不发送；提审内容为教程当前编辑值，无额外参数）

## 响应

### 成功响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 25,
    "status": "pending",
    "submitCount": 1
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| data.status | String | 待审核，进入管理员审核队列 |
| data.submitCount | Integer | 累计提审次数（submit_count+1 后的值），驱动审核队列"修改版 v2+"标识 |

### 失败场景

| HTTP 状态码 | code | 触发条件 | message 示例 |
|-------------|------|----------|--------------|
| 401 | 401 | 未登录 | "未登录或登录已失效" |
| 403 | 403 | 登录角色为 user | "无权限执行该操作" |
| 404 | 404 | 教程 id 不存在 | "教程不存在" |
| 400 | 400 | 必填缺失：标题 / 所属分类 / 摘要 / 正文任一为空 | "请补全标题/分类/摘要/正文后再提交" |
| 400 | 400 | 长度越界：标题 >100 字 / 摘要 >200 字 / 标签 >5 个 | "标题不超过 100 字 / 摘要不超过 200 字 / 标签最多 5 个" |
| 409 | 409 | 所属分类已停用 | "所属分类已停用，请选择启用的分类" |
| 409 | 409 | 教程当前状态非草稿（含已下架态未编辑直接提审的非法迁移） | "该教程状态已变化，请刷新" |

## 业务规则

- 提审：草稿→待审核，submit_count+1，进入管理员审核队列（按提交时间倒序展示）（来源：PRD §7.6/§7.7、AC-FN-07、AC-RULE-05）
- 必填校验：标题 / 所属分类 / 摘要 / 正文四项齐备才可提审，缺失阻断并高亮对应字段；所属分类仅启用节点可选（来源：AC-EG-01、AC-FN-07、AC-RULE-18）
- 提审后前台列表 / 搜索 / 推荐均不返回该教程（无线上过审版本不可见，来源：AC-FN-07、AC-RULE-02）
- 状态机非法迁移后端拒绝：仅草稿态可提审；已下架教程需先经编辑保存自动回审（合法路径），直接提审被拒（来源：AC-RULE-05、AC-EG-09）
- 重复提审由前端按钮防抖（仅首次生效，静默防抖），后端以状态机 409 兜底（来源：PRD §9、AC-EG-03）

## 调用示例

### 正常请求

```bash
curl -X POST 'http://localhost:3000/api/tutorials/25/submit' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer b7e2d9f4a1c80356' \
  -d '{}'
```

### 预期响应

```json
{"code":0,"message":"ok","data":{"id":25,"status":"pending","submitCount":1}}
```
