# FE-02 - 教程详情页·阅读主体与导航（#/detail/:id）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`ui/ui_portal_detail.html`

> 来源：[tech-design.md#7-前端架构第-8-章](../../design/tech-design.md#7-前端架构第-8-章) / PRD §7.3 前台·教程详情页

新建 `web/src/portal/pages/Detail.tsx`（路由 `#/detail/:id`，挂入 IT-03 交付的 portal App.tsx 路由表），本任务交付**阅读主体与导航**部分，互动区（收藏/评价/分享按钮区）由 FE-03 追加：

1. 页面初始化加载 `GET /api/tutorials/:id` 并渲染：面包屑、标题区（作者/更新时间/浏览/收藏/标签）、工具条、图文正文（published 快照）、视频区（外链播放、失效占位）、步骤序号、注意事项、信息卡（右侧）。
2. 富文本正文渲染前做脚本剥离（白名单标签，剥离 script/事件属性，AC-NF-04 同口径）。
3. 目录锚点：右侧目录列出正文标题，点击平滑滚动定位，滚动时 IntersectionObserver 高亮当前小节（UI-IXD-03）。
4. 字号三档：标准/大/特大，仅影响正文区域（CSS 变量），档位 localStorage 本地记忆（AC-RULE-21 / UI-IXD-04）。
5. 上一篇/下一篇：同分类相邻教程跳转，无相邻时按钮置灰不可点击（UI-IXD-05）。
6. 阅读进度：按滚动位置节流保存（登录态）`POST /api/histories/:tutorialId`，同一教程单值覆盖、跨端取最新值（AC-RULE-11）；保存失败静默重试一次、仍失败保留本地最近值（AC-EG-17）；再次进入有进度时弹"继续阅读"提示并定位（AC-FN-04 / UI-IXD-11）。
7. 404 分支：已下架（reason:offline）渲染"该教程已下架"提示横幅 + 同类推荐（正文不可见）；从未过审（invisible）渲染"该教程不存在或暂不可见"（AC-FN-20 / AC-EG-10）。
8. 弱网体验：文字先行渲染、图片 loading=lazy + 加载中占位，视频不自动播放（AC-EG-13）。

### 交互操作

> 每条操作必须包含以下全部描述项，缺一不可。
> 每条操作必须标注来源（PRD 章节 或 tech-design.md 章节），不允许无来源的内容。

**1. 页面初始化加载**
- 来源：[tech-design.md#7-前端架构第-8-章](../../design/tech-design.md#7-前端架构第-8-章) / PRD §7.3 内容展示
- 触发：进入 #/detail/:id（含列表页/收藏/历史/推荐卡跳入，或 :id 参数变化）
- 前置条件：无（游客可看；shared/api.ts 自动附加本地 token）
- 操作：GET /api/tutorials/{id}（无必填参数；携带本地 token 时返回 myFavorite/myFeedback/myProgress）
- Loading 状态：整页骨架占位，文字先行渲染（AC-EG-13 弱网文字优先）
- 期望效果：标题区/工具条/正文（sanitize 后快照）/视频区/步骤/侧栏信息卡与目录渲染完成；viewCount 已含本次 +1；myProgress>0 且 <100 时显示继续阅读提示条
- 空态处理：404 分支见"已下架/不可见提示页"两态（AC-FN-20 / AC-EG-10）；网络错误显示重试按钮

**2. 目录锚点定位与高亮**
- 来源：PRD §7.3 目录锚点 / UI-IXD-03
- 触发：点击侧栏目录条目；或正文滚动
- 前置条件：正文渲染完成
- 操作：无请求（纯前端：scrollIntoView({behavior:'smooth'})；IntersectionObserver 观察各节标题，rootMargin 预留 sticky 头部 150px）
- Loading 状态：无
- 期望效果：点击目录条目 → 正文平滑滚动到对应标题（UI-IXD-03）；滚动时当前可视小节对应目录条目高亮（.on 态）
- 空态处理：正文无标题结构时目录卡片隐藏

**3. 字号三档切换**
- 来源：PRD §7.3 字号调节 / AC-RULE-21 / UI-IXD-04
- 触发：点击工具条"标准/大/特大"
- 前置条件：无
- 操作：无请求；设置正文容器 CSS 变量 `--fs-article: 15px|17px|19px` 并写入 localStorage（key: portal_article_fs）
- Loading 状态：无
- 期望效果：仅 .article 正文区域字号变化（标题/侧栏/工具条不变）；再次进入页面读取 localStorage 恢复档位与选中态
- 空态处理：localStorage 无记录默认"标准"

**4. 上一篇/下一篇跳转**
- 来源：PRD §7.3 上下篇 / UI-IXD-05
- 触发：点击"← 上一篇"/"下一篇 →"
- 前置条件：data.prev / data.next 非 null
- 操作：无请求，前端路由跳转 #/detail/{prev.id} / #/detail/{next.id}
- Loading 状态：无（目标页自身骨架）
- 期望效果：跳转同分类相邻教程并重新初始化；prev/next 为 null 时对应按钮置灰 disabled（UI-IXD-05 无相邻不可点）
- 空态处理：无

**5. 阅读进度保存（滚动位置节流 + 步骤勾选）**
- 来源：PRD §7.3 阅读进度 / AC-RULE-11 / AC-EG-17
- 触发：正文滚动（节流，如每 3s 或滚动静止后）或勾选步骤圆点
- 前置条件：已登录（未登录不调用接口，静默跳过）
- 操作：POST /api/histories/{id} `{"progress": 0-100 整数}`（滚动口径 = 已滚动深度百分比，与步骤勾选数/总数取较大值）
- Loading 状态：无（静默后台保存，无 UI loading）
- 期望效果：200 后本地记录最近成功值；histories 同用户同教程单行覆盖（AC-RULE-11 跨端取最新值）；步骤勾选即时更新进度条
- 空态处理：请求失败 → 静默重试 1 次 → 仍失败保留本地最近值不打断阅读、无报错弹窗（AC-EG-17）；未登录静默不保存

**6. 继续阅读提示与定位**
- 来源：PRD §7.3 阅读进度 / AC-FN-04 / UI-IXD-11
- 触发：初始化返回 myProgress ∈ (0,100)
- 前置条件：已登录且有历史进度
- 操作：无请求（点击横幅时按 progress 百分比 scrollTo 正文对应位置）
- Loading 状态：无
- 期望效果：显示"继续上次阅读：已完成 {m}/{n} 步（{p}%）…"横幅；点击横幅定位到上次阅读位置；点 ✕ 本会话隐藏（AC-FN-04：再次进入仍弹提示且进度为上次保存值）
- 空态处理：myProgress=null / 0 / 100 时不显示横幅

**7. 已下架/不可见详情分支渲染**
- 来源：[tech-design.md#6-异常处理与校验](../../design/tech-design.md#6-异常处理与校验) / AC-FN-20 / AC-EG-10
- 触发：GET /api/tutorials/{id} 返回 404
- 前置条件：无
- 操作：无二次请求（使用 404 响应 data.reason 与 data.related）
- Loading 状态：骨架结束即渲染提示页
- 期望效果：message="该教程已下架" → 横幅"该教程已下架，正文不可见。"+ 同类推荐卡（可点击跳转）；message="该教程不存在或暂不可见" → 对应空态文案；两种分支正文/目录/进度均不渲染
- 空态处理：related 为空数组时同类推荐区显示"浏览更多"入口按钮
