# FE-03 - 教程详情页·互动区（收藏/评价+留言/分享/关联推荐）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`ui/ui_portal_detail.html`

> 来源：[tech-design.md#7-前端架构第-8-章](../../design/tech-design.md#7-前端架构第-8-章) / PRD §7.3 收藏/评价/留言/分享/关联推荐

在 FE-02 交付的 `web/src/portal/pages/Detail.tsx` 页面骨架上追加**互动区**：

1. 收藏按钮：已收藏态切换、favCount 同步更新（UI-IXD-06）；**未登录点击 → 弹选角色登录（RoleLoginModal），登录后回到原页面原位置且该次收藏自动完成**（AC-FN-03 硬性验收点）。
2. 评价区：有帮助/没帮助二选一互斥高亮、可修改切换（AC-RULE-15 评价唯一可改的交互面）；初始选中态取 `myFeedback`（AC-FN-25 跨端共用同一条评价记录的 PC 侧表现）。
3. 留言框：仅评价选"没帮助"时条件展开，选填 ≤200 字 + 字数计数，提交仅进后台（AC-RULE-20 / UI-IXD-08）。
4. 分享：点击"🔗 分享"按钮 → 调 share 打点并打开 FE-01 的 ShareModal。
5. 关联推荐：详情底部（侧栏"🧩 相关教程" + 正文底部区）渲染同分类 4 篇排除本篇，点击跳转（UI-IXD-16）。
6. 未登录评价：弹登录并提示"登录后即可收藏/评价"，登录后回原位且该次评价被记录（AC-EG-07）。
7. 游客点赞/收藏按钮在未登录态仍可见可点（触发登录引导），不隐藏。

### 交互操作

> 每条操作必须包含以下全部描述项，缺一不可。
> 每条操作必须标注来源（PRD 章节 或 tech-design.md 章节），不允许无来源的内容。

**1. 未登录点击收藏 → 登录弹窗回原位（AC-FN-03 硬性验收）**
- 来源：PRD §7.2 / [tech-design.md#6-异常处理与校验](../../design/tech-design.md#6-异常处理与校验)
- 触发：游客态点击"☆ 收藏"
- 前置条件：本地无 token
- 操作：先弹 RoleLoginModal（不发请求）；用户选角色后 POST /api/auth/role-login `{"erpRole":"sales"}` → 拿 token 存本地 → **自动重放** POST /api/favorites/{id} `-d '{}'`
- Loading 状态：登录请求与收藏请求期间收藏按钮 loading 禁用
- 期望效果：登录弹窗关闭、停留在当前详情页原位置；收藏成功：favCount +1、按钮切换"★ 已收藏"选中态（AC-FN-03：登录后回到原页面原位置且收藏成功）
- 空态处理：用户关闭登录弹窗 → 不收藏、无残留状态；收藏接口 404（教程不可见）→ toast"该教程不存在或暂不可见"

**2. 已登录收藏/取消收藏切换**
- 来源：PRD §7.3 收藏 / UI-IXD-06
- 触发：登录态点击收藏按钮
- 前置条件：已登录
- 操作：myFavorite=false → POST /api/favorites/{id}（空体）；myFavorite=true → DELETE /api/favorites/{id}
- Loading 状态：按钮 loading 禁用防连点
- 期望效果：按响应 `{favorited, favCount}` 更新按钮态与计数（刷新后一致）；取消后计数 -1
- 空态处理：401（登录失效）→ 弹 RoleLoginModal 回原位重放（同操作 1）；网络失败 → toast 重试提示且按钮态回滚

**3. 评价选择与切换提交**
- 来源：PRD §7.3 评价 / AC-FN-05 / AC-RULE-15 / UI-IXD-07
- 触发：登录态点击"有帮助"或"没帮助"后点"提交反馈"（或选票即提交，按原型 vote+submitFb 两段：选择即时高亮，提交落库）
- 前置条件：已登录；已选择某一评价
- 操作：POST /api/feedbacks/{id} `{"helpful": 1|0, "comment": string|null}`
- Loading 状态：提交按钮 loading 禁用
- 期望效果：成功后按响应 `{helpful, helpfulYes, helpfulNo}` 更新两按钮文案计数与选中态；改选切换成功（旧 -1 新 +1），每人每篇仅保留一条记录可反复修改（AC-RULE-15 评价唯一可改）；"没帮助"选中态高亮（AC-FN-05）
- 空态处理：未选任何评价点提交 → 提示"请先选择「有帮助」或「没帮助」"；401 → 登录弹窗回原位重放该次评价

**4. 游客评价登录引导（AC-EG-07）**
- 来源：PRD §9 权限异常 / AC-EG-07
- 触发：游客态点击"有帮助/没帮助"
- 前置条件：本地无 token
- 操作：弹 RoleLoginModal，副文案"登录后即可收藏/评价"；选角色登录成功后自动提交该次评价（POST /api/feedbacks/{id}）
- Loading 状态：登录中评价按钮禁用
- 期望效果：回到原页面且该次评价被记录（按钮选中态 + 计数 +1）
- 空态处理：关闭登录弹窗 → 评价不提交、无选中残留

**5. 留言条件展开与提交**
- 来源：PRD §7.3 留言 / AC-RULE-20 / UI-IXD-08
- 触发：选中"没帮助"
- 前置条件：已登录（或登录引导完成后）
- 表单校验规则：
  | 字段 | 规则 | 错误提示 |
  |------|------|---------|
  | comment | 选填、≤200 字（maxlength=200 + 实时计数 {n}/200） | 无（超长被输入层拦截；后端 400 时 toast"留言不超过 200 字"） |
- 操作：随评价一起 POST /api/feedbacks/{id} `{"helpful":0,"comment":"..."}`
- Loading 状态：提交按钮 loading
- 期望效果：留言框仅"没帮助"时展开（选"有帮助"收起）；提交成功后留言仅进后台，前台不展示任何留言列表（AC-RULE-20）
- 空态处理：comment 留空提交成功（null）

**6. 分享入口**
- 来源：PRD §7.3 分享 / AC-FN-06 / UI-IXD-09
- 触发：点击"🔗 分享"
- 前置条件：教程可见
- 操作：POST /api/tutorials/{id}/share（静默打点，失败不阻断）→ 打开 ShareModal（FE-01）
- Loading 状态：无（按钮无 loading）
- 期望效果：弹窗展示复制链接 + 二维码；二维码扫码直达小程序同篇教程（ShareModal 内实现，AC-FN-06）
- 空态处理：打点 404 静默

**7. 关联推荐跳转**
- 来源：PRD §7.3 关联推荐 / UI-IXD-16
- 触发：点击侧栏"相关教程"或正文底部推荐卡
- 前置条件：data.related 非空
- 操作：无请求，前端路由跳转 #/detail/{related[i].id}
- Loading 状态：目标页骨架
- 期望效果：4 篇同分类教程（排除本篇）可达对应详情；不足 4 篇显示实际数量
- 空态处理：related 空数组时两个推荐区隐藏（404 分支的同类推荐由 FE-02 渲染）

**8. 页面初始化个性化字段加载**
- 来源：[../../design/api/get-api-tutorials-id.md](../../design/api/get-api-tutorials-id.md) / AC-FN-25
- 触发：进入 #/detail/:id
- 前置条件：本地有 token（由 FE-02 的 GET 请求携带）
- 操作：复用 FE-02 的 GET /api/tutorials/{id} 响应
- Loading 状态：随页面骨架
- 期望效果：myFavorite 驱动收藏按钮初始态；myFeedback 驱动评价选中态（1→有帮助高亮，0→没帮助高亮+留言框展开）；未登录两者为 null → 均为未选中态
- 空态处理：myFeedback=null 无选中
