# FE-04 - 我的页面（#/my：收藏/浏览历史双 Tab）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`ui/ui_portal_my.html`

> 来源：[tech-design.md#7-前端架构第-8-章](../../design/tech-design.md#7-前端架构第-8-章) / PRD §7.4 前台·我的（收藏与历史）

新建 `web/src/portal/pages/My.tsx`（路由 `#/my`，挂入 portal App.tsx 路由表）：

1. 用户信息头（当前登录角色徽章 + "我的学习"标题 + "收藏与阅读进度在 PC / 小程序两端实时同步"副文案）。
2. 双 Tab：收藏列表 / 浏览历史，Tab 徽标显示条数。
3. 收藏列表：按收藏时间倒序；每条显示分类/收藏时间/浏览量/标签；"取消收藏"操作行内生效；**已下架条目灰显 + "已下架"徽章 + 不可点击进入正文 + 同类推荐替代链接**（AC-FN-20 / AC-EG-10 / UI-ELEM-02 样式规格）。
4. 浏览历史：按最近阅读时间倒序；每条显示进度徽章（100% 绿 / 1-99 蓝 / 低进度橙，三档配色）+ mini 进度条 + "继续阅读 →"（<100%）/"重新学习"（=100%）按钮；点击进入详情续读（AC-FN-23）。
5. 未登录访问：GET 接口 401 → 弹选角色登录，登录后回原位加载（AC-FN-03 同机制，AC-FN-15 跨端收藏的 PC 侧展示面）。

### 交互操作

> 每条操作必须包含以下全部描述项，缺一不可。
> 每条操作必须标注来源（PRD 章节 或 tech-design.md 章节），不允许无来源的内容。

**1. 页面初始化加载（含未登录引导）**
- 来源：PRD §7.4 / [tech-design.md#6-异常处理与校验](../../design/tech-design.md#6-异常处理与校验)
- 触发：进入 #/my
- 前置条件：无（未登录也可进入页面，触发登录引导）
- 操作：GET /api/favorites?page=1&pageSize=20 与 GET /api/histories?page=1&pageSize=20（携带本地 token，两 Tab 徽标计数都需要；或仅加载当前 Tab + 懒加载另一 Tab，实现自选但徽标计数须准确）
- Loading 状态：面板骨架占位
- 期望效果：收藏按 favoritedAt 倒序、历史按 updatedAt 倒序渲染；Tab 徽标显示 total
- 空态处理：401 → 弹选角色登录（登录后回 #/my 原位自动重新加载，AC-FN-03 同机制）；list 空 → 空态提示 + 去浏览入口

**2. Tab 切换**
- 来源：PRD §7.4 / UI 原型 .tabs
- 触发：点击"浏览历史"/"收藏列表" Tab
- 前置条件：页面已加载
- 操作：无请求（数据已持有则直接切换；懒加载实现时发对应 GET）
- Loading 状态：懒加载时面板 skeleton
- 期望效果：面板显隐切换，选中 Tab 蓝色下划线高亮；列表保持已加载状态
- 空态处理：对应面板空态

**3. 取消收藏**
- 来源：PRD §7.4 收藏列表 / AC-RULE-09
- 触发：点击条目"取消收藏"
- 前置条件：已登录
- 操作：DELETE /api/favorites/{tutorialId}
- Loading 状态：按钮 loading 禁用 → "已取消"
- 期望效果：成功后该条目从收藏列表移除、Tab 徽标 -1；详情页收藏计数同步口径（fav_count 联动 -1）
- 空态处理：401 → 登录弹窗回原位；失败 → toast 且条目保留

**4. 已下架条目交互限制**
- 来源：PRD §7.4 / AC-FN-20 / AC-EG-10
- 触发：点击 isOffline=true 的条目主体
- 前置条件：无
- 操作：无请求（阻止导航，不跳 #/detail/:id）
- Loading 状态：无
- 期望效果：条目灰显 + "已下架"徽章 + 不可进入正文（点击无效）；同类推荐链接与"浏览更多"可正常跳转；历史面板同规格（进度徽章保留展示）
- 空态处理：无

**5. 历史/收藏条目进入详情续读**
- 来源：PRD §7.4 浏览历史 / AC-FN-23 / UI-IXD-11
- 触发：点击正常条目或"继续阅读 →"/"重新学习"按钮
- 前置条件：条目 isOffline=false
- 操作：无请求，前端路由跳转 #/detail/{tutorialId}（详情页按 myProgress 弹继续阅读提示定位，链路见 FE-02）
- Loading 状态：目标页骨架
- 期望效果：进入详情并从进度处续读（AC-FN-23：从列表点击进入详情的续读交互）；progress=100 按钮文案"重新学习"
- 空态处理：无
