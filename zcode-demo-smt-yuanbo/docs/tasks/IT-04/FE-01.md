# FE-01 - 分享弹窗组件 ShareModal（复制链接 + 小程序二维码 + 分享打点）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`ui/ui_portal_detail.html`（分享弹窗区块：`.mask/#shareMask/.dlg/.link-row/.qr/.qr-cap`）

> 来源：[tech-design.md#7-前端架构第-8-章](../../design/tech-design.md#7-前端架构第-8-章) / PRD §7.3 分享

新建 `web/src/portal/components/ShareModal.tsx` 公共组件（被 FE-03 详情页使用，小程序端详情页后续复用同规格）：

1. 弹窗展示"复制链接"按钮与二维码（UI-IXD-09）：链接行为 PC 端详情 URL，复制成功有"已复制"反馈提示；二维码内容为该教程的**小程序端 URL**，扫码后小程序打开同一篇教程（AC-FN-06）。
2. 二维码用 `qrcode` npm 包按 tech-design §7 生成（不手写二维码算法）。
3. 打开弹窗时调用 `POST /api/tutorials/:id/share` 打点（失败静默不阻断弹窗）。

组件不绑定具体页面状态，通过 props 驱动，便于跨端复用。

### 交互操作

> 每条操作必须包含以下全部描述项，缺一不可。
> 每条操作必须标注来源（PRD 章节 或 tech-design.md 章节），不允许无来源的内容。

**1. 打开分享弹窗（由父组件触发）+ 分享打点**
- 来源：[tech-design.md#7-前端架构第-8-章](../../design/tech-design.md#7-前端架构第-8-章) / PRD §7.3 分享
- 触发：父组件设置 `open=true`（详情页点击"🔗 分享"按钮，见 FE-03）
- 前置条件：教程前台可见（不可见教程本就无分享入口）
- 操作：POST /api/tutorials/{tutorialId}/share（无 Authorization，公开接口，无请求体）
- Loading 状态：打点请求静默进行，弹窗与二维码立即渲染，不显示 loading
- 期望效果：弹窗展示；链接输入框填充 PC 端 URL；qrcode 以 `http://{host}/m.html#/detail/{tutorialId}` 为内容渲染 150×150 二维码（AC-FN-06：扫码直达小程序同篇教程）
- 空态处理：打点失败（含 404）静默忽略，弹窗正常可用；qrcode 渲染异常时降级显示占位方块 + 文案"二维码生成失败，请复制链接"

**2. 复制链接**
- 来源：PRD §7.3 分享 / UI-IXD-09
- 触发：点击"复制"按钮
- 前置条件：弹窗已打开
- 操作：`navigator.clipboard.writeText(pcurl)`（剪贴板 API 不可用时 fallback `input.select() + document.execCommand('copy')`）
- Loading 状态：无 loading，按钮文案即时切换防重复感知
- 期望效果：剪贴板内容 = PC 端详情 URL（打开后直达该教程，AC-FN-06）；按钮文案"已复制"持续 1.5s 后恢复"复制"（复制成功反馈，UI-IXD-09）
- 空态处理：复制 API 全部失败时按钮短暂显示"复制失败"，不弹错误框

**3. 关闭弹窗**
- 来源：UI 原型 `.mask` 点击空白关闭 / ✕ 关闭
- 触发：点击遮罩空白处或右上角 ✕
- 前置条件：弹窗打开
- 操作：回调 `onClose()`（父组件置 open=false），不发请求
- Loading 状态：无
- 期望效果：弹窗隐藏；再次打开重新打点 +1（share_count 按动作计数）
- 空态处理：无
