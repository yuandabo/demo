# FE-05 - 前台浏览检索三页联调验证（tutorials 列表/详情、recommend、categories 四接口契约对齐）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`ui/ui_portal_home.html`、`ui/ui_portal_list.html`、`ui/ui_portal_workbench.html`

> 来源：[tech-design.md#3-api-接口总览](../../design/tech-design.md#3-api-接口总览) / [prd.md#11-非功能需求m13](../../prd/PRD.md#11-非功能需求m13)

以真实后端（IT-01 脚手架 + IT-02 四端点）驱动 portal 三页联调：验证 `GET /api/tutorials`（含 sort=latest|hot、tag 逗号交集补充契约）、`GET /api/tutorials/:id`（详情+上下篇+关联+浏览计数）、`GET /api/recommend`（角色命中集）、`GET /api/categories?withCount=1`（角标计数）与前端实现的契约一致性，修复 FE 侧偏差，登记 BE 侧偏差；完成搜索性能、超时兜底与浏览器兼容实测。详情页页面交互（UI-IXD-10 步骤进度等）属 IT-04，本任务仅完成详情**接口**数据基础验证。

### 前置条件（跨迭代，非任务依赖）

- IT-01：web 脚手架（多入口/AuthContext/shared api）+ server 可启动、种子初始化完成（`POST /api/system/reset` 或 erp.db 重建）
- IT-02：tutorials / categories / recommend 端点 dev-done

### 联调验证矩阵

| # | 验证项 | 操作（curl + 浏览器双通道） | 通过判定 |
|---|--------|------------------------------|---------|
| 1 | 列表 sort 契约 | `curl 'localhost:3000/api/tutorials?sort=latest&pageSize=6'` 与 `sort=hot&pageSize=6` | latest 按 isTop DESC→sort ASC→updated_at DESC；hot 按浏览量倒序；首页两区块渲染一致（AC-FN-22/AC-RULE-17） |
| 2 | tag 交集契约 | `curl '.../api/tutorials?tag=算料,BOM'` | 仅返回同时含两标签教程，单值等价精确匹配（UI-IXD-02） |
| 3 | keyword 三字段 | `curl '.../api/tutorials?keyword=算料'`；浏览器搜"算料" | 命中标题/摘要/标签任一；DevTools 计时 ≤1s（AC-FN-02/AC-NF-01） |
| 4 | categoryId 含子类 | 宫格点击"生产制造"→列表 | 列表=该分类及其子分类前台可见教程，与树计数对账 |
| 5 | 分类角标 | `curl '.../api/categories?withCount=1'`；首页宫格 | 12 个启用一级分类；tutorialCount=0 的格显示"待补充"（AC-FN-01/UI-ELEM-05） |
| 6 | 推荐双口径 | 游客 `curl .../api/recommend`；采购角色登录后再取 | 游客 source=global 全站 Top6；采购 source=role 且**全部来自采购管理+库存管理命中集**、浏览量倒序、不足 6 展示实际数量（AC-FN-17/AC-RULE-16） |
| 7 | 详情接口 | `curl .../api/tutorials/{id}` 连续两次；登录态再取一次 | viewCount 递增 +1；content 读 published_content 快照；prev/next 同分类相邻；related 同分类 4 篇排除本篇；登录态返回 myFavorite/myFeedback/myProgress（UI-IXD-10 步骤进度的数据基础） |
| 8 | 详情不可见分支 | `curl .../api/tutorials/{纯草稿id}` 与 `{已下架id}` | 分别 404"该教程不存在或暂不可见" / 404"该教程已下架"+related 提示页数据 |
| 9 | 超时兜底 | DevTools Network 限速（Slow 3G）触发搜索 | 1s 显示"搜索超时，请重试"，重试与分类浏览两条路径恢复（AC-EG-11） |
| 10 | 工作台入口 | 工作台 4 卡跳转 | #/list?erpModule=produce/purchase/inventory 选中映射分类且列表过滤正确（UI-IXD-14） |
| 11 | 浏览器兼容 | Chrome/Edge 各最新稳定版+上一稳定版走查三页 | 布局无错位、控制台 0 Error；报告登记实测版本清单（AC-NF-03） |
| 12 | 详情首屏口径 | 打开任一详情接口驱动的跳转链路 | 接口响应支撑文字先行渲染基础（AC-NF-02，页面级验收在 IT-04） |

### 偏差处理策略

- FE 侧偏差（字段名/参数/渲染）：本任务内修复并复验
- BE 侧偏差（契约未按 API 文档实现，如 tag 未按交集、sort 缺失）：记录至 frontmatter `doc-drift` 并反馈 IT-02 对应任务修复，修复后回归本矩阵；本任务不直接修改 server 代码
