### 交互操作

**1. 点击顶栏"教程中心"logo / 导航项（UI-IXD-15 全局入口）**
- 来源：[prd.md#71-前台教程首页-cms](../../prd/PRD.md#71-前台教程首页-cms)
- 触发：任意 portal 页面点击 logo 或 4 个导航项之一
- 前置条件：无（游客可点）
- 操作：纯前端路由跳转（HashRouter navigate），无 HTTP 请求
- Loading 状态：无
- 期望效果：地址栏 hash 变为 #/、#/list、#/workbench、#/my，对应页面渲染且该导航项高亮 #00d4ff
- 空态处理：无

**2. 点击角色徽章打开选角色登录弹窗**
- 来源：[prd.md#711-公共账号-租户](../../prd/PRD.md#711-公共账号-租户)
- 触发：点击顶栏角色 pill；或任意接口返回 401（shared/api.ts 派发全局登录事件）
- 前置条件：无
- 操作：打开 RoleLoginModal（无 HTTP）
- Loading 状态：无
- 期望效果：遮罩+弹窗显示 6 角色卡；再点遮罩空白或 ✕ 关闭
- 空态处理：无

**3. 选择角色登录**
- 来源：[prd.md#711-公共账号-租户](../../prd/PRD.md#711-公共账号-租户) / [tech-design.md#7-前端架构第-8-章](../../design/tech-design.md#7-前端架构第-8-章)
- 触发：弹窗内点击任一角色卡
- 前置条件：弹窗已打开
- 操作：`POST /api/auth/role-login`，请求体 `{ "erpRole": "sales|purchase|produce|warehouse|manage|finance" }`，响应取 `data.token / data.user{erpRole,userName}`
- Loading 状态：被点角色卡显示 loading 态、其余卡禁用，防重复提交
- 期望效果：token 与 user 写入 localStorage 并更新 AuthContext → 弹窗关闭 → 角色 pill 更新为"{角色} · {姓名}" → 触发 onLoginSuccess 回调（页面级消费：如 FE-02 首页重新拉取推荐）→ 路由不变（回到原页面原位置，AC-FN-03 机制基础）
- 空态处理：接口失败（非 401）时弹窗内提示"登录失败，请重试"，弹窗不关闭

**4. 登录态恢复（刷新页面）**
- 来源：[tech-design.md#7-前端架构第-8-章](../../design/tech-design.md#7-前端架构第-8-章)
- 触发：携带已登录 localStorage 刷新页面
- 前置条件：localStorage 存在 token
- 操作：`GET /api/auth/me`（Authorization: Bearer {token}）
- Loading 状态：顶栏角色 pill 显示骨架占位
- 期望效果：恢复用户态（pill 显示角色·姓名）；token 失效返回 401 时清除本地态回游客态并触发登录弹窗事件
- 空态处理：无
