## 任务目标

**UI 设计稿路径**：`ui/ui_portal_list.html`

> 来源：[prd.md#72-前台教程列表页-cms](../../prd/PRD.md#72-前台教程列表页-cms) / [tech-design.md#8-非功能实现](../../design/tech-design.md#8-非功能实现)

实现 portal 全部教程列表页：搜索框（命中标题/摘要/标签三字段，1s 内返回，超时兜底）、左侧分类树（两级+计数，含二级展开）、标签多选（交集过滤）、右侧列表（置顶最前带角标）、分页、无结果空态引导（清空筛选+去分类浏览）。筛选状态与 URL query 双向同步（支持宫格/工作台带参进入与刷新保持）。

### 交互操作

**1. 页面初始化加载（含带参进入）**
- 来源：[prd.md#72-前台教程列表页-cms](../../prd/PRD.md#72-前台教程列表页-cms)
- 触发：进入 #/list（可能携带 query：categoryId / erpModule / keyword / tag / page）
- 前置条件：无
- 操作：并行 `GET /api/categories?withCount=1` + `GET /api/tutorials?page=1&pageSize=10`（有筛选参数则拼接：categoryId、keyword、tag 逗号连接）
- Loading 状态：树与列表各自 skeleton
- 期望效果：树渲染（"全部教程"+12 一级+可展开二级，计数=tutorialCount）；列表第一页渲染，置顶教程带角标排最前；若带 `categoryId`（宫格跳入，UI-IXD-01）或 `erpModule`（工作台跳入，UI-IXD-14），树中对应分类选中高亮且列表按其过滤（erpModule 在树中匹配 erpModule 字段的第一个一级分类选中）
- 空态处理：全库为空显示空态引导

**2. 关键词搜索（AC-FN-02 / AC-NF-01）**
- 来源：[prd.md#72-前台教程列表页-cms](../../prd/PRD.md#72-前台教程列表页-cms) / [tech-design.md#8-非功能实现](../../design/tech-design.md#8-非功能实现)
- 触发：输入关键词后点击"搜 索"或回车；或点击热门词
- 前置条件：无（空关键词时提示"请输入关键词，例如：算料"，不发请求）
- 操作：`GET /api/tutorials?keyword={kw}&page=1&pageSize=10`（保留当前 categoryId/tag），fetch 外层 AbortController + `setTimeout(1000)` 竞速
- Loading 状态：搜索按钮 loading 禁用，列表 skeleton
- 期望效果：1s 内返回命中标题/摘要/标签三字段任一的教程列表，摘要行更新计数，URL query 同步 keyword，页码回 1
- 空态处理：无命中时空态引导（"未找到相关教程"+"清空筛选"+"去分类浏览"）

**3. 搜索 1s 超时兜底（AC-EG-11）**
- 来源：[prd.md#9-异常与边界m11](../../prd/PRD.md#9-异常与边界m11) / [tech-design.md#8-非功能实现](../../design/tech-design.md#8-非功能实现)
- 触发：搜索请求超过 1000ms 未返回
- 前置条件：已提交关键词搜索
- 操作：abort 该请求，展示超时提示条（不发新请求直到用户点击）
- Loading 状态：结束 loading，列表保持上次内容
- 期望效果：显示"搜索超时，请重试"；筛选条件（关键词/分类/标签）完整保留；点击"重试"后恢复——服务正常时 1s 内返回结果；用户也可改走左侧分类树点击（分类浏览请求独立，不受超时污染，正常返回列表）——两条恢复路径均可用
- 空态处理：无

**4. 标签多选交集筛选（UI-IXD-02）**
- 来源：[prd.md#72-前台教程列表页-cms](../../prd/PRD.md#72-前台教程列表页-cms)
- 触发：点击/再点任一标签胶囊
- 前置条件：无
- 操作：`GET /api/tutorials?tag={选中标签逗号连接}&page=1&pageSize=10`（如 `tag=MRP,BOM`），与 categoryId/keyword 组合
- Loading 状态：列表 skeleton
- 期望效果：多标签按**交集**过滤（仅同时含所有选中标签的教程返回）；摘要行"标签："显示"算料 + BOM"；URL query 同步 tag；取消全部标签恢复
- 空态处理：交集无结果时空态引导

**5. 分类树节点点击（UI-IXD-01）**
- 来源：[prd.md#72-前台教程列表页-cms](../../prd/PRD.md#72-前台教程列表页-cms)
- 触发：点击"全部教程"/任一一级/二级分类；一级带 ▶ 时点击箭头仅展开收起子级（stopPropagation）
- 前置条件：树已渲染
- 操作：`GET /api/tutorials?categoryId={id}&page=1&pageSize=10`（接口按该分类及其子分类命中）
- Loading 状态：列表 skeleton
- 期望效果：节点选中高亮，列表联动刷新，摘要行"当前分类"更新，URL query 同步 categoryId（"全部教程"清除该参数）
- 空态处理：分类下 0 篇时空态引导（与"待补充"宫格进入场景衔接）

**6. 清空筛选 / 分页切换**
- 来源：[prd.md#72-前台教程列表页-cms](../../prd/PRD.md#72-前台教程列表页-cms)
- 触发：点击"✕ 清空筛选"；点击分页页码/上一页/下一页
- 前置条件：任一筛选生效 / total > pageSize
- 操作：清空=重置 categoryId/keyword/tag/page=1 并重新请求；分页=`GET /api/tutorials?...&page={n}&pageSize=10`
- Loading 状态：列表 skeleton
- 期望效果：清空后恢复全量第一页；分页保持全部筛选条件仅换页，列表刷新后滚动回顶部
- 空态处理：无
