# BE-02 - 教程查询接口（列表全态/详情快照/分享打点）

<!-- REQUIRED:任务目标 -->
## 任务目标

> 来源：[tech-design.md#11-service-函数清单冻结命名评审修复补充](../../design/tech-design.md#11-service-函数清单冻结命名评审修复补充) / [tech-design.md#4-后端架构与处理流程](../../design/tech-design.md#4-后端架构与处理流程)

实现 routes/tutorials.ts 的查询侧 3 端点，service 冻结命名：`listTutorials(filters) / getVisibleTutorial(id) / incrementView(id) / shareTutorial(id)`。

- GET /api/tutorials：双口径列表——无管理参数=前台可见池（VISIBLE_SQL）；status/all 管理参数（admin/operator）=后台全态列表，附 status/rejectReason/submitCount/authorName/hasOnlineVersion/lastOfflineAt 等扩展列（供后台列表页与审核队列 v2 标识，UI-ELEM-07/09 数据源）。支持 categoryId（含子分类）/keyword（标题/摘要/标签）/tag（逗号多值交集）/top/sort（latest/hot）/分页。
- GET /api/tutorials/:id：仅前台可见教程返回 200；读 published_content/published_summary 快照（回审期间旧版不断供）；view_count+1（含游客）；同分类 prev/next 与 related 4 篇；携带登录态附 myFavorite/myFeedback/myProgress；已下架分支 404 + {reason:'offline', related}。
- POST /api/tutorials/:id/share：公开打点，仅对前台可见教程 share_count+1。

<!-- REQUIRED:核心流程 -->
## 核心流程

**1. GET /api/tutorials 列表（双口径）**
- 来源：[../../design/api/get-api-tutorials.md](../../design/api/get-api-tutorials.md)
- 输入：query `categoryId/keyword/tag/top/status/all/sort/page/pageSize`
- 处理逻辑：
  1. 判定口径：无 status/all → 前台可见池（WHERE 拼接 VISIBLE_SQL，且分类须启用：categoryId 命中集排除停用分类）；有 status/all → 鉴权 admin/operator，全态查询（status 优先于 all）
  2. keyword：LIKE 三字段（标题 LIKE / published_summary 或 summary LIKE / tags LIKE），命中范围随列表口径（公开态=前台可见池；管理态 all=1=全态命中）；tag：逗号分隔多值按交集（每值都要命中 tags）
  3. 排序：latest= isTop DESC→sort ASC→updated_at DESC；hot= isTop DESC→view_count DESC
  4. 管理口径 SELECT 附加列：status/reject_reason/submit_count/author_id/authorName（JOIN users.display_name）/hasOnlineVersion（published_content IS NOT NULL）/last_offline_at/created_at；公开口径 summary 读 published_summary（无快照回退 summary）
- 数据库操作：

| 操作 | SQL 骨架 | 说明 |
|------|---------|------|
| SELECT | `SELECT t.*, u.display_name AS author_name FROM tutorials t LEFT JOIN users u ON u.id=t.author_id WHERE {条件} ORDER BY {排序} LIMIT ? OFFSET ?` | 条件含 VISIBLE_SQL / status / category_id IN / LIKE / top |
| SELECT | `SELECT COUNT(*) FROM tutorials t WHERE {同条件}` | total 分页元数据 |

- 输出：`{code:0, data:{list:[...], total, page, pageSize}}`
- 异常处理：管理参数未登录 401；role=user 403；status 非枚举/page<1/pageSize 越界 400 "查询参数不合法"

**2. GET /api/tutorials/:id 详情**
- 来源：[../../design/api/get-api-tutorials-id.md](../../design/api/get-api-tutorials-id.md)
- 输入：path `id`；可选 Authorization
- 处理逻辑：
  1. 查行 → 不存在或不可见（VISIBLE_SQL 不满足且非"已下架"分支）→ 404 "该教程不存在或暂不可见"
  2. 已下架分支（published_content 非空且 status='offline' 或 last_offline_at 语义命中）→ 404 "该教程已下架"，data={reason:'offline', related:[同分类可见 4 篇]}
  3. 可见：content/summary 读快照列；incrementView（view_count+1，含游客，AC-RULE-08）；prev/next=同分类可见池按列表排序取相邻；related=同分类可见 4 篇排除本篇按 view_count 倒序；携带登录态时查 favorites/feedbacks/histories 拼 my* 字段
- 数据库操作：

| 操作 | SQL 骨架 | 说明 |
|------|---------|------|
| SELECT | `SELECT * FROM tutorials WHERE id=?` | 主记录 |
| UPDATE | `UPDATE tutorials SET view_count=view_count+1 WHERE id=?` | 浏览计数（不去重） |
| SELECT | `SELECT id,title FROM tutorials WHERE category_id=? AND {VISIBLE_SQL} AND id<>? ORDER BY ... ` | 上下篇/关联推荐 |

- 输出：`{code:0, data:{id,title,summary,content,videoUrl,tags,categoryId,categoryName,isTop,sort,viewCount(已+1),favCount,helpfulYes,helpfulNo,shareCount,publishedAt,updatedAt,prev,next,related,myFavorite,myFeedback,myProgress}}`
- 异常处理：videoUrl 原样透传（前端加载失败给占位提示"视频暂不可用，可先阅读图文步骤"，AC-EG-02 的数据侧职责）；不可见 404 两种文案见上

**3. POST /api/tutorials/:id/share 打点**
- 来源：[../../design/api/post-api-tutorials-id-share.md](../../design/api/post-api-tutorials-id-share.md)
- 处理逻辑：公开（含游客）→ 校验教程在前台可见池（VISIBLE_SQL）→ share_count+1 → 返回新值
- 数据库操作：`UPDATE tutorials SET share_count=share_count+1 WHERE id=? AND {VISIBLE_SQL}`
- 输出：`{code:0, data:{shareCount}}`
- 异常处理：不可见/不存在 404 "该教程不存在或暂不可见"（文档 code 40404，HTTP 404）

## 验收标准

### 阶段 1：开发验收

- [ ] `getDiagnostics` 0 Error；构建通过
- [ ] curl 列表：`curl 'http://localhost:3000/api/tutorials?keyword=MRP&page=1&pageSize=10'` → 200，仅可见池命中
- [ ] curl 管理态：`curl 'http://localhost:3000/api/tutorials?all=1' -H 'Authorization: Bearer {adminToken}'` → 200，含四态与 rejectReason/submitCount/hasOnlineVersion 扩展列
- [ ] curl 详情：`curl http://localhost:3000/api/tutorials/3 -H 'Authorization: Bearer {userToken}'` → 200，viewCount 较上次 +1，my* 字段非 null
- [ ] curl share：`curl -X POST http://localhost:3000/api/tutorials/2/share` → 200，shareCount 递增
- [ ] curl 异常：user token 带 all=1 → 403；未登录带 status → 401

### 阶段 2：自测验收

- [ ] 口径断言（AC-RULE-01~04）：公开列表不含纯草稿/首次待审核/已下架；含"已发布回审中"（种子 v2 那篇，读旧版快照 summary）；管理态 all=1 四态齐全
- [ ] 已下架教程详情 → 404 "该教程已下架" + data.reason='offline' + related 非空；纯草稿详情 → 404 "该教程不存在或暂不可见"
- [ ] keyword 分别命中标题/摘要/标签三字段各 1 例；tag=MRP,BOM 交集过滤验证；停用分类下教程 keyword 不命中（AC-RULE-07 联动）
- [ ] sort=latest 与 hot 排序差异验证；置顶教程在两口径下均排最前
- [ ] share 对已下架教程 → 404；重复调用 2 次 shareCount +2（不去重）
- [ ] 浏览计数：游客连续打开详情 2 次 viewCount +2（AC-RULE-08）
- [ ] 分页边界：page=1/pageSize=1 正常；pageSize=101 → 400
- [ ] 持久化验证：计数更新落库，重启后保留
