# FE-02 - 统计看板页 #/dashboard

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`ui/ui_admin_dashboard.html`

> 来源：[prd.md#79-后台统计看板-cms](../../prd/PRD.md#79-后台统计看板-cms) / [tech-design.md#7-前端架构第-8-章](../../design/tech-design.md#7-前端架构第-8-章)

实现统计看板页（admin 全量 / operator 只读同视图，均经 FE-01 守卫）：

1. 四指标卡：已发布教程（篇）/ 总浏览量 / 总收藏量 / 平均有帮助率（% ；null 显示"—"，附口径说明文案"零反馈教程显示'—'"）。
2. 浏览量 Top10：纯 CSS 条形图（条长按浏览量比例，Top1 橙色、其余蓝色，进场宽度动画）。
3. 反馈分析表：按"没帮助占比"倒序；每行占比进度条 + 数值；**占比 >50% 的行整行标红（row-red：红底/红字/红条，UI-ELEM-03）**；行首箭头展开"没帮助"留言明细（用户/时间/内容）；零反馈行显示"—"且不可展开。
4. 覆盖度卡片：双 Tab——分类视图（cover-cell 网格，0 篇橙色虚线框 + "待补充/空白区"角标，UI-ELEM-04）与模块聚合视图（模块名+进度条+篇数/覆盖分类数，空白模块橙色）。
5. 空态：空库时各区域显示"暂无数据"引导（AC-EG-12），页面不白屏不报错。

| 区域 | 元素 | 类型 | 位置与尺寸 | 样式与文案 | 默认值/初始状态 | 状态变化 |

| 指标区 | 口径说明 | Text | 页头 page-desc | "指标口径：仅统计前台可见教程（已下架教程历史计数不计入）· 零反馈教程不计入平均有帮助率" | 显示 | 静态 |

| 全局 | 空态 | Div | 各卡片内 | "暂无数据" + 引导入口 | 数据非空时隐藏 | 空库时显示（AC-EG-12） |

### 交互操作

**1. 页面初始化加载**
- 来源：[prd.md#79-后台统计看板-cms](../../prd/PRD.md#79-后台统计看板-cms)
- 触发：进入 #/dashboard
- 前置条件：已登录（admin/operator）
- 操作：并行 GET /api/stats/overview、GET /api/stats/feedback、GET /api/stats/coverage
- Loading 状态：指标卡 skeleton，表格/网格区域骨架占位
- 期望效果：4 指标卡数值、Top10 条形动画展开、反馈表倒序渲染、覆盖度默认分类视图
- 空态处理：三接口均返回空（0/null/[]）→ 各区域"暂无数据"+引导入口，页面不报错（AC-EG-12）

**2. 展开留言明细**
- 来源：[prd.md#79-后台统计看板-cms](../../prd/PRD.md#79-后台统计看板-cms)
- 触发：点击反馈表行首 ▶ 箭头
- 前置条件：该教程有留言（comments 非空；无留言行箭头隐藏）
- 操作：本地展开（无请求）
- 期望效果：箭头旋转 90°，插入黄底明细行列出留言（displayName/updatedAt/comment）；再点收起
- 空态处理：comments=[] 的行不渲染箭头

**3. 覆盖度 Tab 切换**
- 来源：[tech-design.md#7-前端架构第-8-章](../../design/tech-design.md#7-前端架构第-8-章)
- 触发：点击"模块聚合视图" Tab
- 前置条件：coverage 数据已加载
- 操作：本地切换面板
- 期望效果：分类网格隐藏、模块聚合行显示（名称/条/篇数·覆盖分类数）；再点回分类视图
- 空态处理：matrix/modules 为空时对应面板显示"暂无数据"
