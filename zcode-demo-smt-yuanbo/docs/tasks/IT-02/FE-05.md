# FE-05 - 审核队列页 #/review

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`ui/ui_admin_review.html`

> 来源：[prd.md#77-后台审核队列-cms](../../prd/PRD.md#77-后台审核队列-cms) / [tech-design.md#7-前端架构第-8-章](../../design/tech-design.md#7-前端架构第-8-章)

实现审核队列页（admin 专属入口，operator 访问时无审核操作权限提示）：

1. 双 Tab："人工审核"（带待审数角标）与"AI 生成（mock）"。
2. 人工审核 Tab：分类筛选下拉；待审卡片列表（按提交时间倒序）——meta 行（分类/作者/提交时间/**修改版 v2+·回审 标识：submitCount≥2 或存在线上过审版本，UI-ELEM-09**/首次提审标识）、标题、修改要点摘要、缩略步骤预览（正文按步骤标题拆分为 1→2→3→4）、操作行（✅ 通过 / ❳ 驳回 / 查看全文 →）。
3. 审核动作：
   - 通过：按钮防抖仅首次生效（AC-EG-19）；成功后卡片变为"已通过并发布 · 审核人 · 时间 · 前台即时可见"，Tab 计数与侧栏角标同步减一。
   - 驳回：自绘弹窗——驳回对象标题、原因 textarea（≤200 字 + 实时计数 n/200）、**原因 ≥5 字才启用确认按钮（前端阻断，提示"原因必填，不少于 5 个字"，AC-FN-09 / AC-RULE-19 前端侧）**、提示"驳回原因将展示在作者的编辑页顶部……"；确认后卡片回草稿、计数减一。
   - 并发互斥：409 "该教程状态已变化，请刷新" → toast + 刷新队列（AC-EG-04）。
4. 查看全文弹窗：按待审核版本（当前编辑值 content）渲染全文，含步骤样式与图片占位；底部注明"审核通过后前台即时替换为该版本"；仅预览不做审核动作。
5. AI 生成 Tab（UI-ELEM-08）：mock 卡片 1 条（"AI 生成"标签、来源说明、半透明展示），通过/驳回/查看全文按钮全部禁用，附说明"本期内仅展示不可操作，v1.1+ 开放"。
6. operator 越权：页面入口由 FE-01 菜单隐藏；直接输 URL 访问时调用接口返回 403 → 页面提示"无权限执行该操作"（AC-FN-18）。

### 交互操作

**1. 队列初始化**
- 来源：[prd.md#77-后台审核队列-cms](../../prd/PRD.md#77-后台审核队列-cms)
- 触发：进入 #/review 或切换分类筛选
- 前置条件：已登录 admin
- 操作：GET /api/tutorials?status=pending&categoryId={?}&page=1&pageSize=20（按提交时间倒序=updatedAt DESC）+ GET /api/categories
- Loading 状态：卡片列表 skeleton
- 期望效果：待审卡片渲染，Tab 与侧栏角标显示 total；submitCount/hasOnlineVersion 驱动"修改版 v2·回审"或"首次提审"标识
- 空态处理：队列为空显示"暂无待审核教程"空态

**2. 审核通过（防抖）**
- 来源：[prd.md#77-后台审核队列-cms](../../prd/PRD.md#77-后台审核队列-cms) / [prd.md#9-异常与边界m11](../../prd/PRD.md#9-异常与边界m11)
- 触发：卡片点"✅ 通过"
- 前置条件：卡片为待审核态
- 操作：POST /api/tutorials/{id}/review `{"action":"approve"}`
- Loading 状态：按钮 loading + 禁用（防抖仅首次生效，无重复迁移，AC-EG-19）
- 期望效果：卡片变为"✅ 已通过并发布 · 审核人 {admin} · {时间} · 前台即时可见"；Tab 计数与侧栏角标 -1（AC-FN-08）
- 空态处理：409 → "该教程状态已变化，请刷新" + 自动刷新队列（运营已撤回场景，AC-EG-04）

**3. 审核驳回（≥5 字前端阻断）**
- 来源：[prd.md#77-后台审核队列-cms](../../prd/PRD.md#77-后台审核队列-cms)
- 触发：卡片点"❳ 驳回" → 弹窗内点"确认驳回"
- 前置条件：原因 trim 长度 ≥5 字（否则确认按钮禁用）
- 表单校验规则：

| 字段 | 规则 | 错误提示 |
|------|------|---------|
| reason | required，trim ≥5 字，≤200 字 | "原因必填，不少于 5 个字"（按钮禁用 + minTip 文案） |

- 操作：POST /api/tutorials/{id}/review `{"action":"reject","reason":"..."}`
- Loading 状态：确认按钮 loading + 禁用
- 期望效果：成功 → 关闭弹窗、卡片标记"已驳回：教程回到草稿状态，原因已写入编辑页顶部告警条"、计数 -1；**后端 400"请填写至少 5 个字的驳回原因"时弹窗保留并提示（双重校验兜底，AC-FN-09 / AC-RULE-19）**；回审版驳回后前台旧版继续在线由后端保证（AC-FN-19，本页仅状态展示）
- 空态处理：无

**4. 查看全文**
- 来源：[prd.md#77-后台审核队列-cms](../../prd/PRD.md#77-后台审核队列-cms)
- 触发：卡片点"查看全文 →"
- 前置条件：卡片数据已含 content
- 操作：本地渲染（数据来自列表接口的当前编辑值 content）
- 期望效果：大弹窗按步骤渲染待审版本全文；底部"审核通过后前台即时替换为该版本"；关闭/仅预览不做审核动作
- 空态处理：content 为空显示"该教程正文为空"
