# FE-06 - 目录管理页 #/category

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`ui/ui_admin_category.html`

> 来源：[prd.md#78-后台目录管理-cms](../../prd/PRD.md#78-后台目录管理-cms) / [tech-design.md#7-前端架构第-8-章](../../design/tech-design.md#7-前端架构第-8-章)

实现目录管理页（admin 专属）：

1. 左侧分类树（两级）：折叠/展开子分类、行选中高亮（联动右侧表单）、排序值展示（#n）、模块映射标签、教程计数角标（0 篇橙色"0 篇 · 待补充"）、行内启停开关、删除入口、拖拽把手（拖拽与排序值两种方式均可调序，UI-IXD-12）。
2. 右侧编辑表单：分类名称（≤50 字）、父分类（限一级，两级约束）、ERP 模块映射（8 选 1 或"不限"，AC-OP-04）、排序值（同级升序）、启用状态开关；保存/重置/删除该分类。
3. 新增分类：右上"＋ 新增分类"进入表单新增态（默认启用、排序值自动 +1），支持一级与二级（AC-OP-08：二级不进首页宫格仅进筛选树）。
4. **删除保护**：删除触发自绘弹窗；分类下有教程时展示 409 阻断态弹窗——"无法删除：该分类下还有 N 篇教程，请先移走。"+ 处理建议（列出教程名，引导迁移后重试，AC-FN-13）；空分类确认后删除。
5. 启停切换：行内开关即时保存，停用行灰显（AC-RULE-06/07 语义提示：停用后前台宫格/筛选隐藏，其下已发布教程仍可经收藏/历史/直达访问）。

### 交互操作

**1. 分类树加载与选中**
- 来源：[prd.md#78-后台目录管理-cms](../../prd/PRD.md#78-后台目录管理-cms)
- 触发：进入 #/category；点击树行
- 前置条件：admin 登录
- 操作：GET /api/categories?withCount=1&all=1
- Loading 状态：树 skeleton
- 期望效果：全量两级树（含停用）渲染；点击行 → 右侧表单回填该节点（名称/父分类/模块/排序/启停）
- 空态处理：树为空显示"暂无分类"引导新增

**2. 新增分类**
- 来源：[prd.md#78-后台目录管理-cms](../../prd/PRD.md#78-后台目录管理-cms)
- 触发：点"＋ 新增分类"→ 填表单 → 保存
- 前置条件：名称非空 ≤50 字；父分类仅可选一级
- 表单校验规则：

| 字段 | 规则 | 错误提示 |
|------|------|---------|
| name | required，trim 非空，≤50 字 | "分类名称不能为空且不超过 50 字" |
| parentId | 可空；仅一级分类可选 | "本期限两级分类，父分类必须为一级分类"（选项即约束） |
| erpModule | 八枚举或"不限"（null） | "erpModule 参数不合法" |
| sort | 1-999 整数 | "排序值须为 1-999 的整数" |

- 操作：POST /api/categories `{name, parentId, sort, erpModule}`
- Loading 状态：保存按钮 loading
- 期望效果：toast"已保存分类：前台宫格与列表顺序按排序值即时更新"；树刷新出现新节点（一级角标"0 篇 · 待补充"，AC-OP-08）；400/404 按后端文案 toast
- 空态处理：无

**3. 编辑分类 / 模块映射 / 启停 / 排序**
- 来源：[prd.md#78-后台目录管理-cms](../../prd/PRD.md#78-后台目录管理-cms)
- 触发：选中节点修改表单后保存；或行内切换启停开关；或拖拽行/改排序值
- 前置条件：同新增校验（名称/枚举）
- 操作：PUT /api/categories/{id} `{name?, parentId?, sort?, status?, erpModule?}`（启停与排序共用）
- Loading 状态：按钮/开关 loading
- 期望效果：保存成功 toast + 树刷新；**模块映射保存后提示"角色推荐与 ERP 内嵌入口将按新映射生效"（AC-OP-04）**；停用行灰显 + 提示条说明前台影响（AC-RULE-06/07）；排序调整后树顺序即时变化（UI-IXD-12）
- 空态处理：无

**4. 删除分类（409 阻断弹窗）**
- 来源：[prd.md#78-后台目录管理-cms](../../prd/PRD.md#78-后台目录管理-cms) / [prd.md#9-异常与边界m11](../../prd/PRD.md#9-异常与边界m11)
- 触发：行内"删除"或表单"删除该分类"
- 前置条件：admin
- 二次确认：空分类 → 确认弹窗"确认删除分类《{name}》？"；**有教程 → 阻断弹窗（AC-FN-13）**
- 操作：DELETE /api/categories/{id}
- Loading 状态：确认按钮 loading
- 期望效果：**409 "该分类下还有 N 篇教程，请先移走" → 阻断弹窗展示 N 与迁移建议，分类保留在树中（删除保护，AC-FN-13，必须实现）**；409 子分类存在 → "该分类下存在子分类，请先处理"；200 → 树移除该节点
- 空态处理：无
