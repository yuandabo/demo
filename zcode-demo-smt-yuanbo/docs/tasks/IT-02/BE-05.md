# BE-05 - 教程上下架与复制置顶

<!-- REQUIRED:任务目标 -->
## 任务目标

> 来源：[tech-design.md#11-service-函数清单冻结命名评审修复补充](../../design/tech-design.md#11-service-函数清单冻结命名评审修复补充) / [tech-design.md#4-后端架构与处理流程](../../design/tech-design.md#4-后端架构与处理流程)

实现教程生命周期动作 4 端点，service 冻结命名：`offlineTutorial / republishTutorial / copyTutorial / setTopAndSort`。

- POST /api/tutorials/:id/offline：admin 专属；已发布→已下架，last_offline_at=now（AC-RULE-04 可见性派生列），留痕（操作时间）；三端下一次请求即不可见（AC-OP-03）。
- POST /api/tutorials/:id/republish：admin 专属；已下架→已发布，清 last_offline_at，不重审、无待审核中间态，计数延续（AC-FN-11）。
- POST /api/tutorials/:id/copy：admin/operator；任意状态→生成新草稿，标题+"（副本）"（>96 字截断源标题再拼接），浏览/收藏/有帮助/没帮助/分享/提审次数清零，快照列与驳回原因清空（AC-FN-12 / AC-RULE-14）。
- PUT /api/tutorials/:id/top：admin/operator；isTop=1 仅已发布（否则 409 "仅已发布教程可置顶"），取消置顶与调 sort 不限状态。

<!-- REQUIRED:核心流程 -->
## 核心流程

**1. POST /:id/offline 下架**
- 来源：[../../design/api/post-api-tutorials-id-offline.md](../../design/api/post-api-tutorials-id-offline.md)
- 处理逻辑：admin 鉴权 → 404 → 转移表 offline（仅 published，否则 409）→ UPDATE status='offline', last_offline_at=now, updated_at=now；浏览/收藏计数保留
- 数据库操作：`UPDATE tutorials SET status='offline', last_offline_at=datetime('now','localtime'), updated_at=datetime('now','localtime') WHERE id=? AND status='published'`
- 输出：`{code:0, data:{id, status:'offline', lastOfflineAt}}`
- 异常处理：operator/user 403 "无权限执行该操作"；非已发布 409 "该教程状态已变化，请刷新"；404/401

**2. POST /:id/republish 重新发布**
- 来源：[../../design/api/post-api-tutorials-id-republish.md](../../design/api/post-api-tutorials-id-republish.md)
- 处理逻辑：admin 鉴权 → 404 → 转移表 republish（仅 offline，否则 409）→ UPDATE status='published', last_offline_at=NULL；不进审核队列、不动快照列与计数
- 数据库操作：`UPDATE tutorials SET status='published', last_offline_at=NULL, updated_at=datetime('now','localtime') WHERE id=? AND status='offline'`
- 输出：`{code:0, data:{id, status:'published', viewCount, favCount}}`（计数回显=下架前数值）
- 异常处理：未登录 401 "未登录或登录已失效"；operator/user 403 "无权限执行该操作"；非已下架状态 409 "该教程状态已变化，请刷新"；教程不存在 404 "教程不存在"

**3. POST /:id/copy 复制**
- 来源：[../../design/api/post-api-tutorials-id-copy.md](../../design/api/post-api-tutorials-id-copy.md)
- 处理逻辑：鉴权（admin/operator）→ 404 源存在性 → 计算新标题：源标题长度 ≤96 → 原样+"（副本）"；>96 → 截断至 96 字再拼接（96+4=100 不超上限）→ INSERT 新记录：status='draft'、author_id=当前操作人、计数列全部 0（view/fav/helpful_yes/helpful_no/share/submit_count）、published_content/published_summary/published_at=NULL（纯草稿不可见）、reject_reason=NULL、is_top=0、sort=100；源记录完全不动
- 数据库操作：`INSERT INTO tutorials(title,category_id,summary,content,video_url,tags,status,author_id, ...) VALUES(新标题,源值...,'draft',当前用户,...计数全 0...)`
- 输出：`{code:0, data:{id(新), title(含副本), status:'draft', viewCount:0, favCount:0, helpfulYes:0, helpfulNo:0, shareCount:0, createdAt}}`
- 异常处理：401/403（user）/404；无状态限制（任意状态可复制）

**4. PUT /:id/top 置顶与排序**
- 来源：[../../design/api/put-api-tutorials-id-top.md](../../design/api/put-api-tutorials-id-top.md)
- 输入：body `{ isTop: 0|1, sort? }`
- 校验规则：

| 字段 | 规则 | 失败返回 |
|------|------|---------|
| isTop | required，枚举 0/1 | 400 "isTop 必须为 0 或 1" |
| sort | 0-9999 整数，默认保持原值 | 400 "isTop 必须为 0 或 1"（参数不合法） |

- 处理逻辑：鉴权 → 404 → isTop=1 时校验 status='published'，否则 **409 "仅已发布教程可置顶"** → UPDATE is_top/sort
- 数据库操作：`UPDATE tutorials SET is_top=?, sort=COALESCE(?, sort) WHERE id=?`
- 输出：`{code:0, data:{id, isTop, sort, status}}`
- 异常处理：置顶状态校验 409；401/403/404/400

## 验收标准

### 阶段 1：开发验收

- [ ] `getDiagnostics` 0 Error；构建通过
- [ ] curl 下架：`curl -X POST http://localhost:3000/api/tutorials/12/offline -H 'Content-Type: application/json' -H 'Authorization: Bearer {adminToken}' -d '{}'` → 200，status=offline，lastOfflineAt 非空
- [ ] curl 重发布：`curl -X POST http://localhost:3000/api/tutorials/12/republish -H 'Authorization: Bearer {adminToken}' -d '{}'` → 200，计数延续
- [ ] curl 复制：`curl -X POST http://localhost:3000/api/tutorials/3/copy -H 'Authorization: Bearer {operatorToken}' -d '{}'` → 200，标题含"（副本）"
- [ ] curl 异常：operator 调 offline → 403 "无权限执行该操作"；草稿教程 top isTop=1 → 409 "仅已发布教程可置顶"

### 阶段 2：自测验收

- [ ] **非法迁移 409（显式验收）**：pending 教程 offline → 409 "该教程状态已变化，请刷新"；published 教程 republish → 409；状态均保持不变
- [ ] 下架效果（AC-OP-03）：下架后 GET /api/tutorials 列表/keyword 检索下一请求即不返回；详情 404 "该教程已下架"；last_offline_at 落库（AC-RULE-04）
- [ ] 重发布（AC-FN-11）：republish 后前台下一请求即返回；不出现 pending 中间态；view/fav 计数与下架前一致
- [ ] 复制（AC-FN-12 / AC-RULE-14）：新记录 status=draft、六类计数与 submit_count 全 0、published_content NULL（前台不可见）、源教程状态与计数不变；作者=复制操作人；97 字源标题 → 新标题恰 100 字（96+4）
- [ ] 置顶排序：已发布置顶后列表口径 isTop=1 排最前；取消置顶/调整 sort 在 draft 状态也放行；sort 传 10000 → 400
- [ ] 权限矩阵：user 四端点全 403；operator 仅 copy/top 放行
- [ ] 持久化验证：offline→republish 链路后 sqlite 中 last_offline_at=NULL、status='published'
