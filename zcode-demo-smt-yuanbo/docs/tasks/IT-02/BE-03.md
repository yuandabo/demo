# BE-03 - 教程创作写入（阶段 1 前置：先执行 curl 新建标题含"并发回归"的草稿教程用于阶段 3 乐观锁验证）（新建/保存回审/纯草稿删除）

<!-- REQUIRED:任务目标 -->
## 任务目标

> 来源：[tech-design.md#4-后端架构与处理流程](../../design/tech-design.md#4-后端架构与处理流程) / [tech-design.md#11-service-函数清单冻结命名评审修复补充](../../design/tech-design.md#11-service-函数清单冻结命名评审修复补充)

实现教程编辑器的 3 个写入端点（service 命名对齐 §11 风格：`createTutorial / updateTutorial / deleteTutorial`）：

- POST /api/tutorials：admin/operator 新建，创建即草稿（AC-OP-05），长度越界保存草稿同样阻断（AC-RULE-18）。
- PUT /api/tutorials/:id：按当前状态分流保存——草稿仍草稿（可反复覆盖）；已发布/已下架自动回审 pending（AC-FN-10，经 INFRA-01 转移表 editResubmit）；待审核内容覆盖状态保持 pending；baseUpdatedAt 乐观锁并发拦截（AC-EG-05）。
- DELETE /api/tutorials/:id：**删除保护：仅"从未通过审核的纯草稿"（published_content IS NULL）可删；存在线上过审版本一律 403 "存在线上过审版本的教程不可删除，请以下架归档代替"（AC-OP-06，必须实现）**；operator 仅可删本人名下纯草稿。

<!-- REQUIRED:核心流程 -->
## 核心流程

**1. POST /api/tutorials 新建（创建即草稿）**
- 来源：[../../design/api/post-api-tutorials.md](../../design/api/post-api-tutorials.md)
- 输入：body `{ title, categoryId, summary?, content?, videoUrl?, tags? }`
- 校验规则：

| 字段 | 规则 | 失败返回 |
|------|------|---------|
| title | required，trim 非空，≤100 字 | 400 "请填写标题" / 400 "标题不超过 100 字" |
| summary | 可空（草稿落空串），≤200 字 | 400 "摘要不超过 200 字" |
| content | 可空（草稿落空串），富文本 HTML | —（提审时必填，归 BE-04） |
| tags | ≤5 个 | 400 "标签最多 5 个" |
| categoryId | 须存在 | 404 "所属分类不存在" |
| categoryId | 须为启用分类 | 409 "所属分类已停用，请选择启用的分类" |

- 处理逻辑：鉴权（admin/operator）→ 校验 → tags JSON 序列化 → 插入：status='draft'、author_id=当前用户、is_top=0、sort=100、计数列 0、reject_reason=NULL、快照列 NULL
- 数据库操作：`INSERT INTO tutorials(title,category_id,summary,content,video_url,tags,status,author_id) VALUES(?,?,?,?,?,?,'draft',?)`
- 输出：`{code:0, data:{id, title, categoryId, status:'draft', createdAt, updatedAt}}`
- 异常处理：未登录 401；role=user 403 "无权限执行该操作"

**2. PUT /api/tutorials/:id 保存（回审分流 + 乐观锁）**
- 来源：[../../design/api/put-api-tutorials-id.md](../../design/api/put-api-tutorials-id.md)
- 输入：path `id`；body `{ title?, categoryId?, summary?, content?, videoUrl?, tags?, baseUpdatedAt? }`（不传不改；videoUrl 传 null 清除外链）
- 处理逻辑：
  1. 鉴权 → 404 教程存在性 → 长度校验（标题 ≤100 字 / 摘要 ≤200 字 / 标签 ≤5 个，越界 400 返回对应文案）
  2. 乐观锁：baseUpdatedAt 非空且 ≠ 库中 updated_at → 409 "他人已保存新版本，请刷新后合并"
  3. 分类校验：不存在 404 / 停用 409
  4. 状态分流（经 INFRA-01 转移表）：当前 draft → 保持 draft；当前 published 或 offline → editResubmit → status='pending'（AC-FN-10：编辑回审，快照列不动，前台旧版不断供）；当前 pending → 覆盖内容、状态保持 pending
  5. 单语句 UPDATE：传入字段 + status + updated_at=now（"最近更新"依据）；published_content/published_summary 永不触碰
- 数据库操作：`UPDATE tutorials SET {字段}, status=?, updated_at=datetime('now','localtime') WHERE id=? AND updated_at=?`（乐观锁条件化）
- 输出：`{code:0, data:{id, status, updatedAt}}`（status 为保存后状态）
- 异常处理：见上（401/403/404/400/409×2）

**3. DELETE /api/tutorials/:id 删除（纯草稿保护）**
- 来源：[../../design/api/delete-api-tutorials-id.md](../../design/api/delete-api-tutorials-id.md)
- 输入：path `id`
- 处理逻辑：鉴权 → 404 存在性 → **删除保护判定：published_content IS NOT NULL（已发布/已下架/回审驳回落草稿但旧版在线）→ 403 "存在线上过审版本的教程不可删除，请以下架归档代替"** → operator 且 author_id≠当前用户 → 403 "无权限执行该操作"（admin 可删任意纯草稿）→ 物理删除
- 数据库操作：

| 操作 | SQL 骨架 | 说明 |
|------|---------|------|
| SELECT | `SELECT published_content IS NOT NULL AS has_online, author_id, status FROM tutorials WHERE id=?` | 删除保护与归属判定 |
| DELETE | `DELETE FROM tutorials WHERE id=?` | 仅纯草稿放行（二次确认由前端承载） |

- 输出：`{code:0, message:"已删除", data:null}`
- 异常处理：保护 403、越权 403、不存在 404、未登录 401

## 验收标准

### 阶段 1：开发验收

- [ ] `getDiagnostics` 0 Error；构建通过
- [ ] curl 新建：`curl -X POST http://localhost:3000/api/tutorials -H 'Content-Type: application/json' -H 'Authorization: Bearer {operatorToken}' -d '{"title":"销售订单 13 态状态说明","categoryId":1,"summary":"...","content":"<h2>一</h2>","tags":["销售订单"]}'` → 200，status=draft
- [ ] curl 保存：`curl -X PUT http://localhost:3000/api/tutorials/25 -H 'Authorization: Bearer {operatorToken}' -d "{\"title\":\"并发回归标题v2\",\"baseUpdatedAt\":\"$BASE_TS\"}"（先执行 BASE_TS=$(curl -s "http://localhost:3000/api/tutorials?all=1&keyword=并发回归" -H "Authorization: Bearer {operatorToken}" | python -c "import sys,json;print(json.load(sys.stdin)['data']['updatedAt'])" 取值）` → 200，返回分流后 status
- [ ] curl 异常：user token → 403；title 空 → 400 "请填写标题"；标题 101 字 → 400 "标题不超过 100 字"

### 阶段 2：自测验收

- [ ] **删除保护（显式验收）**：对已发布种子教程 DELETE → 403 "存在线上过审版本的教程不可删除，请以下架归档代替"；对自建纯草稿 DELETE → 200 "已删除"，管理列表不再返回（AC-OP-06）
- [ ] operator 删除他人（admin）名下纯草稿 → 403 "无权限执行该操作"，列表中仍存在
- [ ] 保存分流三态：draft 保存仍 draft；published 保存 → pending 且前台 GET /api/tutorials 仍返回旧版快照（AC-FN-10）；offline 保存 → pending 且前台保持不可见
- [ ] 乐观锁：用过期 baseUpdatedAt 保存 → 409 "他人已保存新版本，请刷新后合并"（AC-EG-05）
- [ ] 长度越界：标题 101/摘要 201/标签 6 个 → 400 对应文案；摘要/正文为空的草稿保存成功（必填仅在提审校验，AC-OP-05）
- [ ] 停用分类：PUT/POST 指向停用分类 → 409 "所属分类已停用，请选择启用的分类"
- [ ] videoUrl 传 null 清除外链；tags 落库 JSON 数组文本、列表接口反序列化为数组
- [ ] 持久化验证：新建/保存后 sqlite 查询 status/updated_at/快照列与预期一致（快照列不变）
