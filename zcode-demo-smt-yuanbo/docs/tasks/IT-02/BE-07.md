# BE-07 - 推荐位接口 GET /api/recommend

## 任务目标

实现 `GET /api/recommend?erpRole=`（src/routes/misc.ts，service 函数 `buildRecommend(erpRole)`，tech-design §11 冻结命名）。游客/未传 erpRole → 全站前台可见教程浏览量 Top6；已登录角色 → 按 PRD §7.1 角色-模块映射（销售→销售管理；采购→采购管理、库存管理；生产→生产制造、项目管理；仓库→库存管理；财务→人事财务、销售管理；管理→全部 8 模块）取命中集内可见教程浏览量 Top6；命中集不足 6 条返回实际数量。取数口径必须复用 db.ts 导出的 VISIBLE_SQL（回审期间旧版参与排序）。接口文档：docs/design/api/get-api-recommend.md。

## 核心流程

1. 解析 erpRole（可选）→ 查 categories 取启用且映射命中的一级分类 id 集
2. 基础 WHERE = VISIBLE_SQL + 启用分类过滤（角色分支）→ ORDER BY view_count DESC LIMIT 6
3. 返回列表字段与 GET /api/tutorials 卡片字段一致（title/summary/tags/view_count/...）

## 验收标准

1. `curl "http://localhost:3000/api/recommend"` 返回 ≤6 条，按浏览量倒序，全部为前台可见教程（AC-RULE-16 未登录分支）
2. `curl "http://localhost:3000/api/recommend?erpRole=purchase"` 返回条目全部来自采购/库存映射分类（AC-FN-17）
3. 造 1 条已发布教程进入编辑回审（待审核态），推荐结果仍含该教程（旧版数据参与，VISIBLE_SQL 验证）
4. 停用分类下教程不出现在结果中（AC-EG-14 第 2 点）
