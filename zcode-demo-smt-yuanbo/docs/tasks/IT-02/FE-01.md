# FE-01 - admin 应用骨架与登录页

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`ui/ui_admin_login.html`

> 来源：[tech-design.md#7-前端架构第-8-章](../../design/tech-design.md#7-前端架构第-8-章) / [tech-design.md#2-现有代码基础与仓库结构](../../design/tech-design.md#2-现有代码基础与仓库结构)

搭建管理后台应用骨架并实现登录页（其余 5 页本任务仅挂占位路由，页面实现归 FE-02~FE-06）：

1. admin.html 入口 + `web/src/admin/App.tsx`（HashRouter + AuthProvider 接线，复用 IT-01 shared/api.ts 统一 fetch 与 token 注入）。
2. 路由表：#/login、#/dashboard、#/tutorial、#/tutorial/edit/:id（含 :id=new 新建）、#/review、#/category（对齐 menu-tree 后台 6 页）。
3. 登录页：账号/密码、密码可见切换、错误提示"账号或密码错误"（统一文案，不区分原因）、演示账号提示卡（admin/operator）、登录成功按角色跳转（admin→#/dashboard，operator→#/tutorial）。
4. Sidebar 公共组件（5 个内容页共用，满足公共组件独立三条件）：240px 深色侧栏、品牌区、菜单（统计看板/教程管理/审核队列/目录管理 + AI 生成审核"预留"置灰项）、审核队列角标数（GET /api/tutorials?status=pending 的 total）、角色显隐（operator 仅见"教程管理"+"统计看板"）、底部版本信息。
5. 路由守卫：无后台会话直接输入任意后台 URL → 跳转 #/login，不展示任何后台数据（AC-EG-06）；顶栏（面包屑 + 头像/角色名）与登出。

### 交互操作

**1. 登录提交**
- 来源：[prd.md#711-公共账号-租户](../../prd/PRD.md#711-公共账号-租户) / [tech-design.md#7-前端架构第-8-章](../../design/tech-design.md#7-前端架构第-8-章)
- 触发：点击"登 录"按钮（或表单回车）
- 前置条件：账号/密码非空（空则聚焦提示）
- 操作：POST /api/auth/login `{ username, password }`（与 API 契约 post-api-auth-login.md、IT-01/BE-01 一致）
- Loading 状态：按钮 loading + 禁用
- 期望效果：code=0 → token/user 存 AuthContext+localStorage → admin 跳 #/dashboard、operator 跳 #/tutorial；code≠0 → 错误条显示"账号或密码错误"（统一文案）
- 空态处理：无

**2. 未登录访问后台路由（守卫）**
- 来源：[prd.md#9-异常与边界m11](../../prd/PRD.md#9-异常与边界m11)
- 触发：无 token 状态下直接输入 #/dashboard 等后台 URL
- 前置条件：AuthContext 无后台会话
- 操作：本地路由守卫拦截（不发任何数据请求，不渲染页面骨架外的数据区）
- 期望效果：重定向 #/login，后台数据零暴露（AC-EG-06）
- 空态处理：后台无任何会话数据可展示，登录页表单保持默认值（账号/密码预填）

**3. 侧边栏角标取数**
- 来源：[tech-design.md#3-api-接口总览](../../design/tech-design.md#3-api-接口总览)
- 触发：登录成功进入任意内容页 / 审核动作后全局刷新事件
- 前置条件：已登录
- 操作：GET /api/tutorials?status=pending&page=1&pageSize=1
- 期望效果：菜单"审核队列"右侧显示 total 数字；total=0 时隐藏角标
- 空态处理：请求失败静默隐藏角标
