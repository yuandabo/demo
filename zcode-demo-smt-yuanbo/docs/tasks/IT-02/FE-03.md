# FE-03 - 教程列表页 #/tutorial

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`ui/ui_admin_tutorial_list.html`

> 来源：[prd.md#76-后台教程管理-cms](../../prd/PRD.md#76-后台教程管理-cms) / [tech-design.md#7-前端架构第-8-章](../../design/tech-design.md#7-前端架构第-8-章)

实现后台教程管理列表页：

1. 筛选栏：状态下拉（全部/草稿/待审核/已发布/已下架）、分类下拉（GET /api/categories 树形展示）、关键词输入（回车/按钮触发）+ 重置。
2. 表格列：标题（含副行标签与"置顶"角标、驳回原因提示行）/分类/作者/状态（**四态彩色标签，UI-ELEM-07**）/浏览/收藏/有帮助率/置顶排序/更新时间/操作。无前台数据的状态（草稿/首次待审核）计数列显示"—"。
3. 行内操作按状态渲染（UI-ELEM-07 删除保护入口语义）：published→编辑/下架/复制；pending→编辑(禁用+title"待审核状态请先撤回")/撤回/复制；draft→编辑/提审/复制/删除；offline→编辑/重新发布/复制。**删除按钮仅对 hasOnlineVersion=false 的草稿渲染**；下架/删除均为自绘二次确认弹窗（非 confirm()）。
4. 置顶与排序：星标开关（仅已发布可点，否则禁用 title"仅已发布教程可置顶"）+ 排序值数字框（0-999，失焦保存）。
5. 分页：页码 + 总数统计（含各状态计数汇总文案）。
6. operator 权限：下架/重发布入口隐藏（admin 专属）；403 统一提示"无权限执行该操作"。

### 交互操作

**1. 列表初始化与筛选**
- 来源：[prd.md#76-后台教程管理-cms](../../prd/PRD.md#76-后台教程管理-cms)
- 触发：进入 #/tutorial；或筛选条件变化/回车/点搜索/重置/翻页
- 前置条件：已登录（admin/operator）
- 操作：GET /api/tutorials?all=1&status={?}&categoryId={?}&keyword={?}&page={n}&pageSize=10 + GET /api/categories（分类下拉）
- Loading 状态：表格 skeleton
- 期望效果：全态列表 + 分页元数据；筛选后保持条件刷新
- 空态处理：list 为空显示"暂无数据"空态插画与引导

**2. 下架（二次确认）**
- 来源：[prd.md#76-后台教程管理-cms](../../prd/PRD.md#76-后台教程管理-cms)
- 触发：published 行点"下架"
- 前置条件：admin 角色（operator 不渲染入口）
- 二次确认：自绘 Modal 标题"⬇️ 下架确认"，内容"确认下架《{title}》吗？下架后前台不可见……可随时重新发布"，按钮"取消"/红色"确认下架"
- 操作：POST /api/tutorials/{id}/offline `{}`
- Loading 状态：确认按钮 loading
- 期望效果：行状态变"已下架"（红标签、计数列变灰、操作列换为 编辑/重新发布/复制）；409 时提示"该教程状态已变化，请刷新"并刷新列表
- 空态处理：无

**3. 重新发布 / 复制 / 撤回 / 提审 / 删除**
- 来源：[prd.md#76-后台教程管理-cms](../../prd/PRD.md#76-后台教程管理-cms)
- 触发：对应操作列按钮
- 前置条件：状态匹配（offline→重新发布；pending→撤回；draft→提审/删除）
- 二次确认：删除需 Modal"🗑 删除教程"（"仅'从未通过审核的纯草稿'可删除，删除后不可恢复"）；其余操作直接执行（提审按钮防抖）
- 操作：POST /api/tutorials/{id}/republish `{}`
      POST /api/tutorials/{id}/copy `{}`
      POST /api/tutorials/{id}/withdraw `{}`
      POST /api/tutorials/{id}/submit `{}`
      DELETE /api/tutorials/{id}
- Loading 状态：行内按钮 loading + 防抖（AC-EG-03：提审仅首次生效，静默防抖无重复提示）
- 期望效果：行状态与操作列按新状态重渲染；复制成功 toast"已复制为新草稿（副本）· 计数清零"；删除成功行移除；403 → toast"无权限执行该操作"；409 → "该教程状态已变化，请刷新"+刷新
- 空态处理：无

**4. 置顶与排序调整**
- 来源：[prd.md#76-后台教程管理-cms](../../prd/PRD.md#76-后台教程管理-cms)
- 触发：点击星标 / 排序值失焦
- 前置条件：星标仅已发布可用；sort 输入 0-999
- 操作：PUT /api/tutorials/{id}/top `{ isTop: 0|1, sort }`
- Loading 状态：星标/输入框短暂禁用
- 期望效果：星标态切换、标题旁"置顶"角标显隐；排序值保存 toast；409"仅已发布教程可置顶"toast
- 空态处理：无
