# BE-06 - 统计看板接口（overview/feedback/coverage）

<!-- REQUIRED:任务目标 -->
## 任务目标

> 来源：[tech-design.md#11-service-函数清单冻结命名评审修复补充](../../design/tech-design.md#11-service-函数清单冻结命名评审修复补充) / [tech-design.md#3-api-接口总览](../../design/tech-design.md#3-api-接口总览)

实现 routes/stats.ts 3 端点，service 冻结命名：`buildOverview / buildFeedbackAnalysis / buildCoverage`。admin/operator 可访问（operator 只读同数据，AC-RULE-23），user 403。**三端点统计口径全部复用 INFRA-01 VISIBLE_SQL（前台可见口径：已下架不计入、回审期间旧版计入，与列表可对账，AC-RULE-08/09）。**

- GET /api/stats/overview：已发布教程数 / 总浏览量 / 总收藏量 / 平均有帮助率（零反馈不计入分母，全零为 null）+ 浏览量 Top10。
- GET /api/stats/feedback：按"没帮助占比"倒序清单，>50% isRed=true（UI-ELEM-03），null 排尾部；附留言明细（仅后台可见）。
- GET /api/stats/coverage：启用分类 × 前台可见教程数矩阵（0 篇 isBlank=true，UI-ELEM-04）+ 按模块映射聚合视图。
- 空库时返回 0/null/空数组，页面不报错（AC-EG-12）。

## 核心流程

**1. GET /api/stats/overview 总览**
- 来源：[../../design/api/get-api-stats-overview.md](../../design/api/get-api-stats-overview.md)
- 处理逻辑（全部限定 VISIBLE_SQL）：
  1. publishedCount = 可见教程行数；totalViewCount = SUM(view_count)；totalFavCount = favorites 表总行数（当前有效收藏，取消即减，AC-RULE-09）
  2. avgHelpfulRate：逐教程计算 helpful_yes/(helpful_yes+helpful_no)（分母 0 的教程跳过），再对有效教程取算术平均，百分比保留 1 位小数；全部零反馈 → null
  3. topViewed：可见教程按 view_count 倒序取 10 条 {id,title,viewCount}
- 数据库操作：

| 操作 | SQL 骨架 | 说明 |
|------|---------|------|
| SELECT | `SELECT COUNT(*) c, SUM(view_count) v, SUM(helpful_yes) hy, SUM(helpful_no) hn FROM tutorials WHERE {VISIBLE_SQL}` | 指标汇总 |
| SELECT | `SELECT COUNT(*) FROM favorites` | 总收藏量 |
| SELECT | `SELECT id,title,view_count FROM tutorials WHERE {VISIBLE_SQL} ORDER BY view_count DESC LIMIT 10` | Top10 |

- 输出：`{code:0, data:{publishedCount,totalViewCount,totalFavCount,avgHelpfulRate,topViewed[]}}`
- 异常处理：401/403；空库返回 0/0/0/null/[]（不抛错，AC-EG-12）

**2. GET /api/stats/feedback 反馈分析**
- 来源：[../../design/api/get-api-stats-feedback.md](../../design/api/get-api-stats-feedback.md)
- 处理逻辑：查可见教程 {tutorialId,title,helpfulYes,helpfulNo} → 应用层计算 notHelpfulRate = helpful_no/(yes+no)（分母 0 → null，isRed=false 不参与判定）与 isRed（rate>50 → true）→ 排序：notHelpfulRate DESC，null 排最后 → 关联 feedbacks 取留言明细 {userId,displayName(JOIN users),comment,updatedAt}（仅本端点可见）
- 数据库操作：`SELECT t.id,t.title,t.helpful_yes,t.helpful_no FROM tutorials t WHERE {VISIBLE_SQL}` + `SELECT f.user_id,u.display_name,f.comment,f.updated_at FROM feedbacks f JOIN users u ON u.id=f.user_id WHERE f.tutorial_id=? AND f.comment IS NOT NULL ORDER BY f.updated_at DESC`
- 输出：`{code:0, data:{list:[{tutorialId,title,helpfulYes,helpfulNo,notHelpfulRate,isRed,comments[]}]}}`
- 异常处理：401/403

**3. GET /api/stats/coverage 覆盖度**
- 来源：[../../design/api/get-api-stats-coverage.md](../../design/api/get-api-stats-coverage.md)
- 处理逻辑：
  1. matrix：启用分类（status='enabled'）全量（含一二级，sort 升序）× 各分类可见教程数（一级含子分类汇总）；tutorialCount=0 → isBlank=true
  2. modules：按 erp_module 聚合（categoryCount=该模块启用分类数，tutorialCount=模块内可见教程数汇总；isBlank 判定=模块 tutorialCount 为 0 时 true）
- 数据库操作：`SELECT * FROM categories WHERE status='enabled' ORDER BY sort ASC` + `SELECT t.category_id, COUNT(*) FROM tutorials t WHERE {VISIBLE_SQL} GROUP BY t.category_id`
- 输出：`{code:0, data:{matrix:[{categoryId,name,parentId,erpModule,tutorialCount,isBlank}], modules:[{erpModule,moduleName,categoryCount,tutorialCount,isBlank}]}}`
- 异常处理：401/403；空库 matrix/modules=[]（AC-EG-12）

## 验收标准

### 阶段 1：开发验收

- [ ] `getDiagnostics` 0 Error；构建通过
- [ ] curl 总览：`curl http://localhost:3000/api/stats/overview -H 'Authorization: Bearer {adminToken}'` → 200，4 指标 + topViewed ≤10 条
- [ ] curl 反馈：`curl http://localhost:3000/api/stats/feedback -H 'Authorization: Bearer {adminToken}'` → 200，list 倒序
- [ ] curl 覆盖：`curl http://localhost:3000/api/stats/coverage -H 'Authorization: Bearer {adminToken}'` → 200，matrix 含启用分类
- [ ] curl 异常：未登录 → 401；user token → 403 "无权限执行该操作"

### 阶段 2：自测验收

- [ ] 口径对账（AC-RULE-08/09）：下架一篇已发布教程 → publishedCount/totalViewCount 同步下降（已下架历史计数不计入），与 GET /api/tutorials?all=1（total 对账） 的 total 一致；回审中教程（种子 v2）计入
- [ ] 标红判定（UI-ELEM-03）：种子中没帮助占比 >50% 的条目 isRed=true；零反馈条目 notHelpfulRate=null、isRed=false、排清单尾部
- [ ] 空白区判定（UI-ELEM-04）：0 篇启用分类（种子"系统设置"）isBlank=true；停用分类不入 matrix
- [ ] modules 聚合：每模块 tutorialCount=该模块启用分类计数之和；无映射分类不进 modules
- [ ] 留言明细：仅含 comment 非空记录，displayName 来自 users 联表（AC-RULE-20 后台可见性）
- [ ] 空库空态（AC-EG-12）：清空 tutorials 后三端点均 200 不报错（overview 0/0/0/null/[]、feedback []、coverage 空数组）
- [ ] operator token 三端点放行且数据同 admin（只读）
