# FE-04 - 教程编辑器页 #/tutorial/edit/:id

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`ui/ui_admin_tutorial_edit.html`

> 来源：[prd.md#76-后台教程管理-cms](../../prd/PRD.md#76-后台教程管理-cms) / [tech-design.md#7-前端架构第-8-章](../../design/tech-design.md#7-前端架构第-8-章)

实现教程编辑器页（:id=new 为新建）：

1. **驳回原因告警条**：教程为草稿且 rejectReason 非空时，页面顶部黄色告警条"驳回原因（审核人 · 时间）：{reason}"+关闭按钮（AC-RULE-19 作者可见语义）。
2. 基本信息表单：标题（≤100 字 + 实时字数 14/100，超限红色）、所属分类（仅启用节点）、摘要（≤200 字 + 字数）、标签 chips（回车添加、≤5 个、点 × 移除）、视频外链（mp4 直链，可选）。
3. **RichEditor 组件**（本页专用，内联开发于 web/src/admin/components/RichEditor.tsx）：contenteditable 编辑区 + 工具条（B 加粗 / H 步骤标题 H2 / 无序·有序列表 / 插入图片 URL / 插入视频外链 / 预览切换）；步骤标题自动编号渲染。
4. 右侧操作卡：当前状态标签 + 自动保存提示（"30 秒前已自动保存"/"刚刚已自动保存"）、元信息（作者/创建/更新/前台数据，草稿期显示"—"）、置顶开关 + 排序值（0-999）、操作按钮组（保存草稿/提交审核/预览前台效果/删除草稿）。
5. 保存与自动保存：手动"保存草稿" + **30 秒间隔自动保存草稿（防抖，内容变化才发 PUT）**；再次进入编辑器检测到本地未提交快照时弹"已恢复未保存的编辑内容"提示（localStorage 承载）。
6. 提审：四项必填（标题/分类/摘要/正文）校验，缺失阻断并高亮对应字段，提示"请补全标题/分类/摘要/正文后再提交"（AC-EG-01）；长度越界同样阻断高亮（AC-RULE-18）；按钮防抖仅首次生效（AC-EG-03）；成功后状态变待审核并返回列表。
7. 保存分流提示：已发布/已下架教程保存后 toast"已保存，进入回审"（AC-FN-10）；409 乐观锁冲突提示"他人已保存新版本，请刷新后合并"。

### 交互操作

**1. 编辑器加载（新建/编辑）**
- 来源：[prd.md#76-后台教程管理-cms](../../prd/PRD.md#76-后台教程管理-cms)
- 触发：路由进入 #/tutorial/edit/:id
- 前置条件：已登录；编辑态需教程存在于管理列表
- 操作：:id=new → GET /api/categories（表单空初始化）；:id 数字 → 并行 GET /api/tutorials?all=1&pageSize=100（编辑表单需读"当前编辑值"而非线上快照，故走管理列表口径取本行：title/summary/content/videoUrl/tags/status/rejectReason/isTop/sort/updatedAt）+ GET /api/categories
- Loading 状态：表单 skeleton
- 期望效果：标题/分类/摘要/标签/视频/正文/状态/rejectReason/isTop/sort 回填；驳回告警条按条件显示
- 空态处理：教程不存在 → 提示页 + 返回列表

**2. 保存草稿（手动 + 30s 自动）**
- 来源：[prd.md#76-后台教程管理-cms](../../prd/PRD.md#76-后台教程管理-cms) / [prd.md#9-异常与边界m11](../../prd/PRD.md#9-异常与边界m11)
- 触发：点击"💾 保存草稿"；或内容变化后 30s 计时到点（防抖：距上次保存无变化不发）
- 前置条件：标题/摘要/标签长度合规（越界阻断保存并高亮，AC-RULE-18）；必填完整性不校验（仅提审校验，AC-OP-05）
- 操作：新建首次 POST /api/tutorials `{title,categoryId,summary,content,videoUrl,tags}`；后续 PUT /api/tutorials/{id} `{title,categoryId,summary,content,videoUrl,tags, baseUpdatedAt:加载值}`
- Loading 状态：按钮 loading；自动保存静默（不阻塞编辑）
- 期望效果：toast"已保存草稿（可反复保存，不影响前台）"；updatedAt 刷新；已发布/已下架态保存 → 状态变 pending + toast"已保存，进入回审"（AC-FN-10）；409 → "他人已保存新版本，请刷新后合并"（AC-EG-05 前端提示）
- 空态处理：本地存有未提交快照 → 进入时弹"已恢复未保存的编辑内容"确认恢复

**3. 提交审核（必填校验 + 防抖）**
- 来源：[prd.md#76-后台教程管理-cms](../../prd/PRD.md#76-后台教程管理-cms) / [prd.md#9-异常与边界m11](../../prd/PRD.md#9-异常与边界m11)
- 触发：点击"📤 提交审核"
- 前置条件：先保存最新内容
- 表单校验规则：

| 字段 | 规则 | 错误提示 |
|------|------|---------|
| 标题 | required，≤100 字 | "请补全标题/分类/摘要/正文后再提交"（缺失高亮标题） |
| 所属分类 | required（启用节点） | "请补全标题/分类/摘要/正文后再提交"（缺失时高亮分类选择框） |
| 摘要 | required，≤200 字 | "请补全标题/分类/摘要/正文后再提交"（缺失时高亮摘要输入框） |
| 图文正文 | required（富文本非空） | "请补全标题/分类/摘要/正文后再提交"（缺失时高亮编辑区） |

- 操作：POST /api/tutorials/{id}/submit `{}`
- Loading 状态：按钮 loading + 禁用（防抖仅首次生效，静默，AC-EG-03）
- 期望效果：成功 → toast"已提交审核：草稿 → 待审核"→ 返回 #/tutorial（行状态待审核）；400 必填 → 字段高亮 + 提示文案（AC-EG-01）；409 → "该教程状态已变化，请刷新"
- 空态处理：无

**4. 删除草稿（纯草稿） / 置顶排序**
- 来源：[prd.md#76-后台教程管理-cms](../../prd/PRD.md#76-后台教程管理-cms)
- 触发：点击"🗑 删除草稿"（仅纯草稿显示）；切换置顶开关/修改排序值
- 二次确认：删除 confirm 弹窗"仅'从未通过审核的纯草稿'可删除，确认删除《{title}》？"
- 操作：DELETE /api/tutorials/{id}；PUT /api/tutorials/{id}/top `{isTop, sort}`
- 期望效果：删除成功返回列表；置顶/排序 toast"发布后生效"；403"存在线上过审版本的教程不可删除，请以下架归档代替"（删除保护提示）
- 空态处理：无
