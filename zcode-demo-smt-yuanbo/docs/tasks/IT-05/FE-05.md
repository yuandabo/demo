# FE-05 - m 收藏历史 #/favorite（收藏/历史双 Tab，与 PC 同数据源刷新可见）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`ui/ui_m_favorite.html`

> 来源：[prd.md#710-小程序端h5-cms租户](../../prd/PRD.md#710-小程序端h5-cms租户) / [tech-design.md#4-后端架构与处理流程](../../design/tech-design.md#4-后端架构与处理流程)

实现 m 端收藏历史页（替换 FE-01 占位页，TabBar「收藏」active），**与 PC 端同一数据源**（favorites/histories 联合主键表三端同写同读，任一端操作另一端刷新后可见——AC-FN-15）：

1. 顶部「收藏 N / 历史 N」双 Tab 切换 + 「🔄 与 PC 端实时同步」提示条；
2. 收藏 Tab：调 GET /api/favorites，卡片含分类缩略图标、标题、分类徽标、收藏于日期、❤️；**已下架条目灰显 + 「已下架」标签、不可进入正文**（UI-ELEM-02 / AC-RULE-04）；
3. 历史 Tab：调 GET /api/histories，卡片带进度环形徽章（conic-gradient 百分比 / 100% 显示 ✓ 绿色）与最近阅读时间（AC-FN-23 倒序与进度展示的 m 端承载）；
4. 取消收藏：DELETE /api/favorites/:tutorialId，列表局部移除（PC 端刷新后同样不可见）；
5. 未登录进入 → RoleSheet 登录引导，登录后回到本页自动加载。

### 交互操作

> 每条操作必须包含以下全部描述项，缺一不可。
> 每条操作必须标注来源（PRD 章节 或 tech-design.md 章节），不允许无来源的内容。

**1. 页面初始化加载（含登录引导）**
- 来源：[get-api-favorites.md](../../design/api/get-api-favorites.md) / [get-api-histories.md](../../design/api/get-api-histories.md)
- 触发：进入 #/favorite（TabBar 或详情页收藏按钮跳转）
- 前置条件：已登录；**未登录 → 弹 RoleSheet（FE-01），登录后回本页自动加载**
- 操作：并行 GET /api/favorites + GET /api/histories
- Loading 状态：双面板骨架卡占位
- 期望效果：收藏 Tab 显示收藏列表（含计数）；历史 Tab 显示历史列表（最近阅读时间倒序，进度环按 progress）
- 空态处理：收藏空 → 「暂无收藏，去首页逛逛」引导（跳 #/）；历史空 → 「暂无阅读记录」

**2. Tab 切换**
- 来源：[prd.md#710-小程序端h5-cms租户](../../prd/PRD.md#710-小程序端h5-cms租户)
- 触发：点击「收藏」/「历史」Tab
- 前置条件：数据已加载
- 操作：无 HTTP（本地面板切换，数据已缓存）
- Loading 状态：无
- 期望效果：面板切换、Tab 下划线与计数联动
- 空态处理：对应面板空态

**3. 取消收藏**
- 来源：[ac.md#AC-FN-15](../../ac.md)
- 触发：收藏卡片上取消收藏操作（长按/左滑或卡片 ❤️ 点击，按原型以 ❤️ 区域为准）
- 前置条件：已登录且该条目为有效收藏
- 操作：DELETE /api/favorites/{tutorialId}
- Loading 状态：卡片按压反馈，防重复提交
- 期望效果：code=0 → 该卡片从收藏列表移除（局部更新不整页刷新）、Tab 计数 -1；**PC 端收藏列表刷新后同样不可见（同一数据源，联调断言）**
- 空态处理：失败 → toast 且卡片保留

**4. 历史卡片续读跳转**
- 来源：[ac.md#AC-FN-23](../../ac.md) / [ac.md#AC-RULE-11](../../ac.md)
- 触发：点击历史卡片（或收藏卡片）
- 前置条件：条目 isOffline=false
- 操作：HashRouter 导航 `#/detail/{tutorialId}`
- Loading 状态：无
- 期望效果：进入详情页并按最新进度续读（进度环值与详情续读条一致，跨端同值）
- 空态处理：isOffline=true → **点击拦截**，不进入正文（已下架善后）

**5. 进入/刷新获取最新（跨端可见性）**
- 来源：[ac.md#AC-FN-15](../../ac.md) / [tech-design.md#4-后端架构与处理流程](../../design/tech-design.md#4-后端架构与处理流程)
- 触发：重新进入页面或下拉刷新（复用列表页下拉交互模式）
- 前置条件：可能在另一端（PC）刚产生收藏/取消/进度变更
- 操作：重新 GET /api/favorites + GET /api/histories
- Loading 状态：骨架屏
- 期望效果：**PC 收藏教程 T → m 刷新后 T 出现；m 收藏 → PC 刷新后可见**（AC-FN-15 双向）；历史进度环取最新覆盖值（AC-RULE-11：m 读 60% 后 PC 再读 80% → m 刷新显示 80%）
- 空态处理：无
