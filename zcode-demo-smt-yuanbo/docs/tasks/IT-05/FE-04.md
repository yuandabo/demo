# FE-04 - m 详情 #/detail/:id（字号三档 / 进度续读跨端同步 / 评价收藏共用 / 已下架提示页）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`ui/ui_m_detail.html`

> 来源：[prd.md#710-小程序端h5-cms租户](../../prd/PRD.md#710-小程序端h5-cms租户) / [tech-design.md#6-异常处理与校验](../../design/tech-design.md#6-异常处理与校验)

实现 m 端详情页（替换 FE-01 占位页），承接 PC 分享二维码扫码直达（URL 即 `m.html#/detail/:id`），与 PC 同数据源同记录：

1. **正文渲染**：GET /api/tutorials/:id 返回快照正文，富文本 sanitize 白名单渲染（剥离 script/事件属性）；视频区不自动播放（弱网仅提示流量）；视频失效显示占位与提示（AC-EG-02）；
2. **字号三档**：标准/大/特大浮层切换，仅正文区域变化（AC-RULE-21 / UI-IXD-04），档位 localStorage 记忆；
3. **进度续读与跨端同步**：滚动百分比 → 防抖 POST /api/histories/:tutorialId（进度单值覆盖，AC-RULE-11）；再次进入 progress>0 显示「上次读到 N%」续读条，点击定位（UI-IXD-11）；保存失败静默重试、仍失败不弹窗不归零（AC-EG-17 同规则）；
4. **评价共用与收藏切换**：有帮助/没帮助二选一互斥高亮（myFeedback 回显），与 PC 共用同一条反馈记录（AC-FN-25）；「没帮助」展开留言框（≤200 字）；收藏按钮切换已收藏态（AC-FN-03 未登录 → RoleSheet 登录后回原位收藏成功）；
5. **已下架提示页**：404 + reason=offline/invisible → 「该教程已下架，正文不可见」+ 同类推荐可跳转（AC-FN-20 / AC-EG-10 小程序扫码分支）。

### 交互操作

> 每条操作必须包含以下全部描述项，缺一不可。
> 每条操作必须标注来源（PRD 章节 或 tech-design.md 章节），不允许无来源的内容。

**1. 页面初始化加载**
- 来源：[get-api-tutorials-id.md](../../design/api/get-api-tutorials-id.md)
- 触发：进入 #/detail/:id（列表卡片/收藏历史/首页推荐/PC 二维码扫码进入）
- 前置条件：无（游客可看正文）
- 操作：GET /api/tutorials/:id
- Loading 状态：正文区骨架（标题灰条 + 段落灰块），导航先渲染
- 期望效果：code=0 → 渲染分类/标签/标题/meta/摘要/快照正文（sanitize 白名单渲染）；进度>0 时续读条显示 N%；myFeedback 回显评价选中态；收藏按钮按 myFavorite 态显示
- 空态处理：code=404 且 data.reason='offline'|'invisible' → 已下架提示页（横幅 + 正文不可见 + related 同类推荐可跳转）

**2. 阅读进度保存（滚动）**
- 来源：[ac.md#AC-RULE-11](../../ac.md) / [post-api-histories-tutorialId.md](../../design/api/post-api-histories-tutorialId.md)
- 触发：正文滚动（节流/防抖，间隔 ≥2s 或滚动停止）
- 前置条件：已登录（游客不保存进度，不弹登录）
- 操作：POST /api/histories/{tutorialId} `{"progress": {滚动百分比 0-100 整数}}`
- Loading 状态：无（静默后台保存）
- 期望效果：code=0 → 进度单值覆盖保存（同用户同教程仅一条记录）；跨端取最新值
- 空态处理：保存失败 → 静默重试一次，仍失败不弹窗（进度回退至最近一次成功保存值，不归零——AC-EG-17 同规则）

**3. 继续阅读定位**
- 来源：[ac.md#UI-IXD-11](../../ac.md) / [ac.md#AC-FN-04](../../ac.md)
- 触发：进入详情页且历史 progress>0；点击「继续阅读 ›」
- 前置条件：同账号已有该篇进度（PC 或 m 产生，跨端同值）
- 操作：无 HTTP（读取详情响应内进度或 GET /api/histories 数据），点击后 scrollTo 定位
- Loading 状态：无
- 期望效果：续读条显示「上次读到 N%」+ 进度条宽度 N%；点击后正文平滑滚动到对应位置（AC-FN-04：PC 读 60% → m 同账号显示 60%）
- 空态处理：progress=0 → 续读条隐藏

**4. 字号三档切换**
- 来源：[ac.md#AC-RULE-21](../../ac.md) / [ac.md#UI-IXD-04](../../ac.md)
- 触发：点击字号浮层任一档位（标准 15px / 大 17px / 特大 19px）
- 前置条件：详情已渲染
- 操作：无 HTTP（CSS 变量 + localStorage['m-font-size']）
- Loading 状态：无
- 期望效果：**仅正文区域**字号变化（导航/按钮/标签不变）；再次进入保持所选档位（本地记忆）
- 空态处理：无

**5. 收藏切换（含未登录引导）**
- 来源：[ac.md#AC-FN-03](../../ac.md)
- 触发：点击导航收藏按钮
- 前置条件：已登录；未登录 → 先弹 RoleSheet
- 操作：未收藏 → POST /api/favorites/{tutorialId}；已收藏 → DELETE /api/favorites/{tutorialId}
- Loading 状态：按钮按压反馈，请求期间防重复点击
- 期望效果：code=0 → 切换已收藏态（实心/空心 + 文案），favCount 计数 ±1 局部更新；**未登录链路**：弹 RoleSheet → 选角色登录 → 回到原页面原位置且收藏成功（AC-FN-03）
- 空态处理：接口失败 → toast 提示，按钮态不变

**6. 评价与留言（与 PC 共用记录）**
- 来源：[ac.md#AC-FN-25](../../ac.md) / [post-api-feedbacks-tutorialId.md](../../design/api/post-api-feedbacks-tutorialId.md)
- 触发：点击「有帮助」/「没帮助」
- 前置条件：已登录；未登录 → RoleSheet 登录后回原位完成该次评价
- 操作：POST /api/feedbacks/{tutorialId} `{"helpful": 1|0, "comment": "≤200 字（选填，仅没帮助时展示输入）"}`
- Loading 状态：按钮按压反馈
- 期望效果：code=0 → 选中态高亮、二选一互斥可改切换；helpfulYes/helpfulNo 计数更新；PC 已评价（myFeedback）→ 按钮显示同态，m 改评后 PC 刷新即变（AC-FN-25）；「没帮助」展开留言框，提交后收起并提示已记录
- 空态处理：失败 → toast；留言超 200 字输入框截断（maxlength）

**7. 已下架提示页（扫码直达分支）**
- 来源：[ac.md#AC-EG-10](../../ac.md) / [ac.md#AC-FN-20](../../ac.md)
- 触发：GET /api/tutorials/:id 返回 404（reason=offline/invisible）
- 前置条件：教程已下架（收藏/历史/直达链接/扫码进入）
- 操作：无额外请求（使用 404 响应内 related 列表）
- Loading 状态：骨架切换为提示页
- 期望效果：显示「⛔ 该教程已下架，正文不可见」横幅；正文区域被遮蔽不可读；同类推荐（related）列表可点击跳转正常详情；评价/收藏操作条禁用
- 空态处理：related 为空 → 仅横幅

**8. 视频播放（不自动播放）**
- 来源：[ac.md#AC-EG-02](../../ac.md) / [tech-design.md#8-非功能实现](../../design/tech-design.md#8-非功能实现)
- 触发：点击视频区播放按钮
- 前置条件：详情含 videoUrl
- 操作：加载 video 直链（mp4）
- Loading 状态：播放按钮转圈
- 期望效果：弱网环境仅提示流量不自动播放；视频失效 → 占位图 +「视频暂不可用，可先阅读图文步骤」，图文步骤完整不受阻断
- 空态处理：无 videoUrl → 视频区不渲染
