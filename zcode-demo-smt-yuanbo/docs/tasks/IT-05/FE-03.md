# FE-03 - m 列表搜索 #/list（横滑分类 chips + 关键词搜索 1s 兜底 + 下拉刷新）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`ui/ui_m_list.html`

> 来源：[prd.md#710-小程序端h5-cms租户](../../prd/PRD.md#710-小程序端h5-cms租户) / [tech-design.md#8-非功能实现](../../design/tech-design.md#8-非功能实现)

实现 m 端列表搜索页（替换 FE-01 占位页，TabBar「分类」active），与 PC 列表同数据源（GET /api/tutorials 同端点同参数）：

1. 顶部返回导航 + 搜索框（默认聚焦输入态，携带首页传入的分类参数）+ 搜索按钮；
2. 横向滑动的分类 chips（全部 + 12 个启用分类，选中高亮），与 PC 筛选树同口径；
3. 关键词搜索命中标题/摘要/标签三字段，**1s 超时兜底**显示「搜索超时，请重试」（AC-EG-11 移动端同规则）；
4. **下拉刷新**（UI-IXD-13）：列表顶部下拉触发重新请求，显示「下拉刷新…·上次更新 HH:mm」提示条；
5. 教程卡片流：标题关键词高亮、摘要 2 行截断、标签、分类徽标、浏览/收藏 meta；底部「已加载全部 N 篇」提示。

### 交互操作

> 每条操作必须包含以下全部描述项，缺一不可。
> 每条操作必须标注来源（PRD 章节 或 tech-design.md 章节），不允许无来源的内容。

**1. 页面初始化加载**
- 来源：[ac.md#AC-FN-24](../../ac.md)
- 触发：进入 #/list（可能携带 `?categoryId=&name=` 来自首页宫格）
- 前置条件：无（游客可看）
- 操作：GET /api/tutorials?keyword=&categoryId={url 参数}&page=1&pageSize=20；并行 GET /api/categories 渲染 chips
- Loading 状态：卡片区骨架屏（3 张灰卡占位）
- 期望效果：列表渲染第一页；URL 带分类时对应 chip 选中且结果行显示「当前筛选：{分类名}」；命中词标题高亮
- 空态处理：无结果 → 空态引导（「清空筛选」按钮 + 「去分类浏览」入口，文案同 PC 规则 AC-FN-02）

**2. 关键词搜索**
- 来源：[ac.md#AC-FN-24](../../ac.md) / [tech-design.md#8-非功能实现](../../design/tech-design.md#8-非功能实现)
- 触发：输入关键词后点击「搜索」按钮或软键盘回车
- 前置条件：无（空关键词=清空搜索）
- 操作：GET /api/tutorials?keyword={关键词}&categoryId={当前分类}&page=1&pageSize=20，**fetch 设 1s 超时**
- Loading 状态：搜索按钮 loading + 禁用；卡片区骨架屏
- 期望效果：1s 内返回 → 结果行「「{关键词}」相关结果 N 篇」；命中标题/摘要/标签的关键词高亮
- 空态处理：超时 → 显示「搜索超时，请重试」提示条（保留已输入关键词可重试）；服务恢复后重试 1s 内返回；无结果 → 空态引导（AC-EG-11）

**3. 分类 chip 切换**
- 来源：[prd.md#710-小程序端h5-cms租户](../../prd/PRD.md#710-小程序端h5-cms租户)
- 触发：点击任一分类 chip（横向可滑动）
- 前置条件：chips 已加载
- 操作：GET /api/tutorials?keyword={保留}&categoryId={新分类}&page=1&pageSize=20
- Loading 状态：卡片区骨架屏，chips 不可重复点击
- 期望效果：选中 chip 高亮（蓝底白字），列表滚动回顶部并刷新；「全部」chip 清除分类筛选
- 空态处理：该分类 0 篇 → 空态引导

**4. 下拉刷新**
- 来源：[ac.md#UI-IXD-13](../../ac.md)
- 触发：列表已在顶部时继续向下拉动超过阈值（touch 事件，释放触发）
- 前置条件：列表滚动位置在顶部
- 操作：按当前 keyword+categoryId 重新 GET /api/tutorials（page 重置 1）
- Loading 状态：提示条文案变「正在刷新…」，释放后自旋
- 期望效果：返回最新数据（如管理员刚发布的新教程立即出现），提示条更新「上次更新 HH:mm」
- 空态处理：刷新失败 → toast 提示重试，保留原列表

**5. 点击教程卡片**
- 来源：[tech-design.md#7-前端架构第-8-章](../../design/tech-design.md#7-前端架构第-8-章)
- 触发：点击任一卡片
- 前置条件：无
- 操作：HashRouter 导航 `#/detail/{id}`
- Loading 状态：无（详情页自带 loading）
- 期望效果：进入详情页
- 空态处理：无

**6. 发布即刻可见（联调断言）**
- 来源：[ac.md#AC-FN-08](../../ac.md)
- 触发：后台发布新教程后回到列表页刷新/下拉刷新
- 前置条件：后台已发布（无需重启/重登）
- 操作：GET /api/tutorials 同参数重新请求
- Loading 状态：骨架屏
- 期望效果：同一次请求即返回新发布教程（与 PC 同数据源同端点）
- 空态处理：无
