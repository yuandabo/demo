# BE-02 - 学习打卡接口 POST /api/checkins + GET /api/checkins（幂等+10 积分/连续天数/徽章/周历）

<!-- REQUIRED:任务目标 -->
## 任务目标

> 来源：[tech-design.md#11-service-函数清单冻结命名评审修复补充](../../design/tech-design.md#11-service-函数清单冻结命名评审修复补充) / [tech-design.md#4-后端架构与处理流程](../../design/tech-design.md#4-后端架构与处理流程)

实现学习激励两个接口（`server/src/routes/misc.ts` 的 checkin 域）：

1. **POST /api/checkins**：每日打卡。首次打卡 +10 积分；当日重复打卡幂等返回（duplicated=true、pointsAdded=0，积分不再增加）；连续天数 = 昨日有打卡则昨日 streak+1，否则重置为 1；**中断仅清连续天数，不清积分、不回收已获徽章**（AC-RULE-12）。
2. **GET /api/checkins**：打卡页/徽章墙状态聚合——todayChecked、totalPoints、streak、bestStreak、completedTutorials（口径=进度 100% 历史条数，同 AC-RULE-13 分子）、badges（persist=连续 7 天；encyclopedia=累计完成 20 篇）、weekCalendar（本周一至周日 7 天）。

唯一约束：checkins 表 `UNIQUE(user_id, checkin_date)`，日期按服务器本地时间。

### POST /api/checkins

**1. 强制鉴权**
- 来源：[tech-design.md#4-后端架构与处理流程](../../design/tech-design.md#4-后端架构与处理流程)
- 输入：请求头 `Authorization: Bearer {token}`
- 处理逻辑：查 auth_tokens 校验 token，解析 user.id；请求体为空对象或不发送（打卡日期取服务器本地当日）
- 校验规则：

  | 字段 | 规则 | 失败返回 |
  |------|------|---------|
  | Authorization | required，`Bearer {token}` 且 token 存在于 auth_tokens | 401 `{code:401, message:"未登录或登录已失效"}` |

- 输出：`userId`
- 异常处理：未登录 → HTTP 401

**2. 当日记录判定（幂等分支）**
- 来源：[post-api-checkins.md 业务规则](../../design/api/post-api-checkins.md)
- 输入：`userId`、服务器本地日期 `today = yyyy-MM-dd`
- 处理逻辑：查当日唯一记录；存在 → 走幂等分支直接组装响应（不再 INSERT、不加积分）
- 数据库操作：

  | 操作 | SQL 骨架 | 说明 |
  |------|---------|------|
  | SELECT | `SELECT * FROM checkins WHERE user_id = ? AND checkin_date = ?` | 当日打卡记录判定（UNIQUE 保证至多 1 条） |

- 输出：当日记录（存在）或 null（不存在）
- 异常处理：无

**3. 连续天数计算与写入（首次打卡分支）**
- 来源：[AC-RULE-12](../../ac.md) / [post-api-checkins.md 业务规则](../../design/api/post-api-checkins.md)
- 输入：`userId`、`today`
- 处理逻辑：查昨日记录（`date(today, '-1 day')`）；有 → `streak = 昨日.streak + 1`；无（中断或首次）→ `streak = 1`（**中断仅清连续天数，不清积分、不回收已获徽章**）。INSERT 当日记录（points=10、streak）
- 数据库操作：

  | 操作 | SQL 骨架 | 说明 |
  |------|---------|------|
  | SELECT | `SELECT streak FROM checkins WHERE user_id = ? AND checkin_date = ?`（第二参数传 yesterday） | 昨日连续性判定 |
  | INSERT | `INSERT INTO checkins (user_id, checkin_date, points, streak) VALUES (?, ?, 10, ?)` | 写入当日打卡 |

- 事务边界：INSERT 与后续聚合读取在同一同步序列内（node:sqlite DatabaseSync 单连接串行执行，天然原子；UNIQUE 冲突兜底见异常处理）
- 输出：当日记录（含 streak）
- 异常处理：并发同日重复插入触发 UNIQUE 约束 → 捕获后转步骤 2 幂等分支重新读取当日记录返回（不报 500）

**4. 聚合与徽章判定**
- 来源：[AC-RULE-12](../../ac.md) / [AC-RULE-13](../../ac.md)
- 输入：`userId`
- 处理逻辑：`totalPoints = SUM(points)`；徽章判定：`persist` = 当前 streak ≥ 7；`encyclopedia` = histories 中该用户 progress=100 的条数 ≥ 20
- 数据库操作：

  | 操作 | SQL 骨架 | 说明 |
  |------|---------|------|
  | SELECT | `SELECT COALESCE(SUM(points), 0) AS total FROM checkins WHERE user_id = ?` | 累计总积分 |
  | SELECT | `SELECT COUNT(*) AS done FROM histories WHERE user_id = ? AND progress = 100` | 百科达人完成数（口径同 AC-RULE-13 分子） |

- 输出：`{totalPoints, badges}`
- 异常处理：无记录用户 SUM 为 NULL → COALESCE 归 0

**5. 组装响应**
- 来源：[post-api-checkins.md 成功响应](../../design/api/post-api-checkins.md)
- 输入：步骤 2/3 的当日记录 + 步骤 4 聚合
- 处理逻辑：首次 → `message:"打卡成功", pointsAdded:10, duplicated:false`；幂等 → `message:"今日已打卡", pointsAdded:0, duplicated:true`
- 输出：`{code:0, message, data:{ checkinDate, pointsAdded, totalPoints, streak, badges, duplicated }}`

### GET /api/checkins

**1. 强制鉴权**
- 来源：[tech-design.md#4-后端架构与处理流程](../../design/tech-design.md#4-后端架构与处理流程)
- 输入/处理/输出：同 POST 步骤 1（401 同文案）

**2. 打卡聚合统计**
- 来源：[get-api-checkins.md 业务规则](../../design/api/get-api-checkins.md)
- 输入：`userId`
- 处理逻辑：`totalPoints = SUM(points)`；`streak`：今日有记录取今日记录 streak，今日无则取昨日记录 streak（昨日也无则 0，表示连续中断清零）；`bestStreak = MAX(streak)`（历史最长）；`completedTutorials = progress=100 历史条数`
- 数据库操作：

  | 操作 | SQL 骨架 | 说明 |
  |------|---------|------|
  | SELECT | `SELECT COALESCE(SUM(points),0) AS total, MAX(streak) AS best FROM checkins WHERE user_id = ?` | 积分与最长连续 |
  | SELECT | `SELECT streak FROM checkins WHERE user_id = ? AND checkin_date IN (today, yesterday) ORDER BY checkin_date DESC LIMIT 1` | 当前连续天数（今日优先，无今日取昨日，均无归 0） |
  | SELECT | `SELECT COUNT(*) AS done FROM histories WHERE user_id = ? AND progress = 100` | 完成教程数（AC-RULE-13 分子口径） |

- 输出：聚合指标
- 异常处理：无记录用户全指标归 0，不报错

**3. 本周日历构造**
- 来源：[get-api-checkins.md 业务规则](../../design/api/get-api-checkins.md)
- 输入：`userId`、服务器本地日期
- 处理逻辑：计算本周一至周日 7 个日期；过去与今天按 checkins 存在性置 `isChecked`，未来日期强制 `false`
- 数据库操作：

  | 操作 | SQL 骨架 | 说明 |
  |------|---------|------|
  | SELECT | `SELECT checkin_date FROM checkins WHERE user_id = ? AND checkin_date BETWEEN ? AND ?`（本周一~周日） | 周内已打卡日期集合 |

- 输出：`weekCalendar: [{date, isChecked}] × 7`
- 异常处理：无

**4. 徽章判定与组装响应**
- 来源：[AC-RULE-12](../../ac.md) / [get-api-checkins.md 成功响应](../../design/api/get-api-checkins.md)
- 输入：聚合指标
- 处理逻辑：`todayChecked = 今日记录存在`；badges 判定同 POST 步骤 4（persist: streak ≥ 7；encyclopedia: completedTutorials ≥ 20）
- 输出：`{code:0, message:"ok", data:{ todayChecked, totalPoints, streak, bestStreak, completedTutorials, badges, weekCalendar }}`
