# FE-02 - m 首页 #/（角色推荐横滑 + 分类宫格 + 消息入口预留 + 打卡横幅）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`ui/ui_m_home.html`

> 来源：[prd.md#710-小程序端h5-cms租户](../../prd/PRD.md#710-小程序端h5-cms租户) / [tech-design.md#7-前端架构第-8-章](../../design/tech-design.md#7-前端架构第-8-章)

实现 m 端首页（替换 FE-01 占位页，套 PhoneShell + TabBar「首页」active）：

1. **深色头部**：logo（云ERP教程中心）、当前角色徽章（点开 RoleSheet 切换角色）、搜索框（点击进 #/list）；
2. **角色推荐横滑**：调 GET /api/recommend 按登录角色取 Top6（不足显示实际数量，AC-RULE-16 口径），横向滑动卡片；
3. **分类宫格**：调 GET /api/categories 渲染 12 个启用一级分类，3 列宫格，角标=该分类前台可见教程数，0 篇显示「待补充」；点击宫格 → `#/list?categoryId={id}`；
4. **消息入口预留卡**：调 GET /api/messages 取第一条 mock 审批待办文案展示，卡片带「预留」标签、点击仅作展示跳转（v1.1 迭代池预留）；
5. **打卡横幅**：已登录时调 GET /api/checkins 显示今日打卡状态（今日未打卡/已连 N 天），点击 → #/checkin；游客态显示固定引导文案。

### 交互操作

> 每条操作必须包含以下全部描述项，缺一不可。
> 每条操作必须标注来源（PRD 章节 或 tech-design.md 章节），不允许无来源的内容。

**1. 页面初始化加载**
- 来源：[tech-design.md#7-前端架构第-8-章](../../design/tech-design.md#7-前端架构第-8-章)
- 触发：进入 #/（或登录态/角色变化后重挂载）
- 前置条件：无（游客可看）
- 操作：并行请求 GET /api/recommend（携带登录态则按角色，未登录全站 Top6）+ GET /api/categories；已登录追加 GET /api/messages?erpRole={user.erpRole}（隐式过滤）+ GET /api/checkins
- Loading 状态：推荐区与宫格显示骨架卡（灰底圆角占位），头部与 TabBar 立即渲染
- 期望效果：推荐横滑 ≤6 条（AC-RULE-16：角色映射分类命中集内浏览量倒序，不足显示实际数量）；宫格 12 个启用一级分类 + 角标计数；消息卡显示第一条 mock 消息摘要；打卡横幅显示 todayChecked/streak
- 空态处理：推荐 0 条 → 区块显示「暂无推荐，去分类浏览」；分类计数 0 → 角标「待补充」（UI-ELEM-05 同规则）

**2. 点击分类宫格**
- 来源：[ac.md#AC-FN-24](../../ac.md)
- 触发：点击宫格任一分类
- 前置条件：宫格数据已加载
- 操作：HashRouter 导航 `#/list?categoryId={id}&name={分类名}`（无 HTTP，跳转后由列表页发请求）
- Loading 状态：无
- 期望效果：进入列表页且对应分类 chip 选中、列表刷新为该分类数据
- 空态处理：无

**3. 点击搜索框**
- 来源：[prd.md#710-小程序端h5-cms租户](../../prd/PRD.md#710-小程序端h5-cms租户)
- 触发：点击头部搜索框
- 前置条件：无
- 操作：导航 `#/list`（聚焦输入态由列表页处理）
- Loading 状态：无
- 期望效果：进入列表页搜索输入态
- 空态处理：无

**4. 点击消息入口卡（预留）**
- 来源：[get-api-messages.md 业务规则](../../design/api/get-api-messages.md)
- 触发：点击消息卡
- 前置条件：GET /api/messages 返回非空
- 操作：无接口写操作（预留入口仅展示）
- Loading 状态：无
- 期望效果：跳转 `#/list`（原型行为：仅作展示引导浏览教程）；卡片文案为最新一条 mock 消息 title/tutorialTitle
- 空态处理：list 为空 → 消息卡隐藏

**5. 点击打卡横幅**
- 来源：[prd.md#710-小程序端h5-cms租户](../../prd/PRD.md#710-小程序端h5-cms租户)
- 触发：点击横幅任意位置
- 前置条件：无（游客点击先进 #/checkin 由该页引导登录）
- 操作：导航 `#/checkin`（横幅文案数据来自初始化时的 GET /api/checkins）
- Loading 状态：无
- 期望效果：进入打卡页；已登录时横幅准确显示 todayChecked（今日未打卡/已打卡）与 streak（已连 N 天）
- 空态处理：GET /api/checkins 401（游客）→ 横幅显示固定引导文案，不报错

**6. 切换角色刷新推荐**
- 来源：[ac.md#AC-RULE-16](../../ac.md)
- 触发：点击角色徽章 → RoleSheet 选择新角色（FE-01 组件回调）
- 前置条件：RoleSheet 登录成功
- 操作：重新 GET /api/recommend（新 token 按新角色过滤）+ GET /api/messages?erpRole={新角色}
- Loading 状态：推荐区骨架屏
- 期望效果：推荐位全部来自新角色映射分类（采购 → 采购管理/库存管理），区块标题角色名同步更新
- 空态处理：新角色命中集为空 → 显示实际数量（0 条时空态文案）

**7. 管理员发布新教程后重新进入/刷新（联调断言）**
- 来源：[ac.md#AC-FN-08](../../ac.md)
- 触发：后台发布新教程后刷新或重新进入首页（与列表页 FE-03 同口径）
- 前置条件：后台已发布新教程（无需重启服务/重新登录）
- 操作：GET /api/recommend（或宫格角标经 GET /api/categories）刷新
- Loading 状态：骨架屏
- 期望效果：推荐位候选集下一次加载即包含该教程（是否入位按浏览量 Top6 排序）；宫格角标计数 +1——与 PC 同数据源、同一次请求即返回
- 空态处理：无

## 调用接口

> 接口定义维护在独立的 API 文档中，前端根据此文档 mock 数据开发。

| 接口 | 文档路径 | 调用说明 |
|------|---------|---------|
| GET /api/recommend | [../../design/api/get-api-recommend.md](../../design/api/get-api-recommend.md) | 调用参数：无（Authorization 携带即按角色）；使用响应字段：`data.list[].{id,title,summary,categoryName,viewCount,favCount}` |
