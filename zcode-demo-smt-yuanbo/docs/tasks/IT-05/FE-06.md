# FE-06 - m 学习打卡 #/checkin（本周日历卡 / 积分卡 / 徽章墙 / 打卡幂等交互）

<!-- REQUIRED:任务目标 -->
## 任务目标

**UI 设计稿路径**：`ui/ui_m_checkin.html`

> 来源：[prd.md#710-小程序端h5-cms租户](../../prd/PRD.md#710-小程序端h5-cms租户)

实现 m 端学习打卡页（替换 FE-01 占位页，TabBar「打卡」active），数据来自本迭代 BE-02 两个接口：

1. **本周日历卡**：GET /api/checkins 的 weekCalendar 渲染 7 格（已打 ✓ 绿 / 中断 ✕ 灰 / 今天「今」橙）；头部统计「连续 N 天 · 本月累计 N 天 · 已打卡 N/7 天」+ 图例；
2. **积分卡**：当前积分（渐变蓝卡片）、「今日打卡后 N+10 分」预告、「+10 积分/天」pill、规则文案「每日可打卡 1 次 +10 积分；中断只清连续天数，不清积分、不扣徽章进度」；
3. **徽章墙**：坚持者（连续打卡 7 天，进度 streak/7）与百科达人（累计完成 20 篇，进度 completedTutorials/20）两张卡，锁定/解锁态 + 进度条 + 说明（完成=阅读进度 100%）；
4. **底部打卡大按钮**：POST /api/checkins；**重复打卡幂等反馈**（duplicated=true → toast「今日已打卡」，积分不增）；按钮防抖；todayChecked=true 时按钮置灰显示已打卡；
5. 未登录进入 → RoleSheet 登录引导。

### 交互操作

> 每条操作必须包含以下全部描述项，缺一不可。
> 每条操作必须标注来源（PRD 章节 或 tech-design.md 章节），不允许无来源的内容。

**1. 页面初始化加载（含登录引导）**
- 来源：[get-api-checkins.md](../../design/api/get-api-checkins.md)
- 触发：进入 #/checkin（TabBar 或首页打卡横幅）
- 前置条件：已登录；**未登录 → 弹 RoleSheet（FE-01），登录后回本页自动加载**
- 操作：GET /api/checkins（Authorization 必填）
- Loading 状态：日历/积分/徽章区块骨架屏
- 期望效果：周历 7 格按 weekCalendar 渲染（过去已打 ✓、中断 ✕、今天待打「今」、未来置灰）；积分卡 totalPoints；徽章墙 streak/7 与 completedTutorials/20 进度；按钮按 todayChecked 启用/置灰
- 空态处理：新用户无记录 → 全指标 0、周历全灰、按钮可点（「打卡后连续 1 天」）

**2. 今日打卡**
- 来源：[ac.md#AC-FN-16](../../ac.md) / [post-api-checkins.md](../../design/api/post-api-checkins.md)
- 触发：点击「📅 今日打卡 +10 积分」大按钮
- 前置条件：已登录且 todayChecked=false
- 操作：POST /api/checkins（空 body `{}`，日期取服务器本地当日）
- Loading 状态：按钮 loading + 禁用（防抖，仅首次生效）
- 期望效果：code=0 且 duplicated=false → toast「打卡成功 +10 积分」；积分卡 +10 动效；今日格变 ✓ 绿；连续天数、徽章进度、按钮说明全部刷新；按钮置灰「今日已打卡」
- 空态处理：接口失败 → toast 错误，按钮恢复可点可重试

**3. 当日重复点击打卡（幂等反馈）**
- 来源：[ac.md#AC-RULE-12](../../ac.md)
- 触发：已打卡状态下再次点击（或按钮置灰前极速双击）
- 前置条件：todayChecked=true 或请求在途
- 操作：POST /api/checkins（重复请求）
- Loading 状态：按钮 loading/禁用
- 期望效果：duplicated=true → toast「今日已打卡」，**积分不再增加**（totalPoints 不变）；页面数据保持一致
- 空态处理：无

**4. 徽章解锁反馈**
- 来源：[ac.md#AC-FN-21](../../ac.md) / [ac.md#AC-FN-16](../../ac.md)
- 触发：打卡后 streak 达 7（坚持者）或 completedTutorials 达 20（百科达人，由阅读完成驱动，本页刷新可见）
- 前置条件：POST/GET 响应 badges 数组含 persist/encyclopedia
- 操作：无额外请求（使用响应 badges 与进度字段）
- Loading 状态：无
- 期望效果：徽章卡由锁定变解锁态（图标去灰、标签「已解锁」、区块标题计数 +1）；连续 7 天打卡获得「坚持者」徽章
- 空态处理：中断后 streak 清零重计，**已解锁徽章不回收**（锁定进度条从 1/7 重新累计，徽章保持解锁——AC-RULE-12）

**5. 去学习跳转**
- 来源：[ui/ui_m_checkin.html](../../ui/ui_m_checkin.html)
- 触发：点击徽章墙「去学习 ›」
- 前置条件：无
- 操作：HashRouter 导航 `#/list`
- Loading 状态：无
- 期望效果：进入列表页（通过阅读完成教程推进百科达人进度）
- 空态处理：无
